# CHG-SEQ-001 消费端观察优先顺序变更

> 状态：已批准  
> 批准日期：2026-08-21  
> 批准指令：项目所有者“优先消费端观察实验开发”

## 变更内容

实施顺序由“先完成Provider门禁和联网信源契约”调整为“先完成消费端观察的无外部调用领域与DTO基础”。原WT-003 Provider门禁顺延为WT-004。

## 不变内容

- 不修改 `CHG-VIS-002` 批准基线的产品、证据、隐私、部署或GEO边界；
- 不降低 `VIS-W01`完整出口条件；
- 不自动操作消费端AI网页；
- 未经人工确认的观察不进入默认指标；
- 不用消费端观察替代Provider API结果；
- 不从页面产品名推断API model ID；
- W01持久化、W02真实采集和W03 UI仍须完成各自前置依赖和门禁。

## 拆分结果

| 顺序     | 任务            | 范围                                               |
| -------- | --------------- | -------------------------------------------------- |
| 1        | WT-003          | Surface、任务状态、证据、token和隐私白名单领域/DTO |
| 2        | WT-005          | 首批产品、允许采集方式、截图/DOM保留和脱敏规则     |
| 3        | W01持久化子任务 | 与共享迁移基础一起落库并完成安全评审               |
| 4        | W02             | 先现场人工录入，再评估获准的浏览器辅助采集         |
| 5        | W03             | 观察工作台、确认页和消费端报告                     |
| 并行顺延 | WT-004          | Provider、方法、预算和保留门禁                     |

## 判断

该调整只改变交付顺序并拆小任务，不改变已批准语义，因此无需建立新的架构ADR。若后续要求无人值守网页自动化、取消人工确认、放宽敏感字段或绕过surface条款门禁，必须另建ADR并重新审批。
