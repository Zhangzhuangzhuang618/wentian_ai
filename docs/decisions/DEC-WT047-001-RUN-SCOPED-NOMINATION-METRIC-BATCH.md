# DEC-WT047-001 运行级自述指标批次完整性

> 状态：已接受  
> 日期：2026-08-23  
> 适用范围：单个消费端`source_nomination`运行的指标输入批次

## 背景

单样本投影不能证明运行的计划、成功、失败分母完整，也不能阻止调用方只挑选已确认提名的响应。自述指标必须从终结运行、完整任务集和服务端Repository构建。

## 决策

- 只允许`succeeded | partial | failed`且有完成时间的`source_nomination`运行构建批次；
- 任务全集必须与不可变快照和运行计数一致；
- 每个confirmed任务必须有唯一不可变响应，每个响应必须有一条review；
- confirmed、needs_review和rejected review均生成一个成功样本；
- 采集失败任务只计入failed，不合成解析样本；
- 每个响应同时校验任务身份、历史Surface版本、Adapter版本和产品标签；
- 批次冻结运行、问题集来源、GEO契约、采集方式、Surface、上下文、归一化版本和样本基数；
- 不允许客户端提交或裁剪样本集合。

## 影响

- WT-034的`successful`覆盖校验可以使用运行事实而不是调用方声明；
- 尚未创建review的成功响应会明确失败，不会被当作无提名；
- GEO同步问题集的契约版本可随运行指标审计；
- 当前批次按需构建，不做生产物化。

## 排除方案

- 只查询confirmed review：遗漏待复核和拒绝分母；
- 为失败采集合成rejected parse样本：混淆采集失败和解析拒绝；
- 允许运行中计算最终批次：分母仍在变化；
- 由客户端提交run元数据：无法证明历史身份。
