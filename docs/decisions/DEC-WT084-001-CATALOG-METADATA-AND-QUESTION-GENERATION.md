# DEC-WT084-001 目录元数据、可搜索选择器与行业问题生成

> 状态：已接受  
> 日期：2026-08-26  
> 适用范围：问天独立版项目、问题集、消费端观察运行目录与问题集创建

## 背景

项目、问题集和实验运行数量增加后，原生长下拉框无法快速定位记录，也无法按业务地区和行业收窄范围。问题集目前还要求逐题手工输入，缺少按行业批量生成常用观察问题的入口。

## 决策

- 项目增加可为空的`industry`和`region`业务元数据；既有项目不根据名称自动推断，迁移后保持未设置；
- 问题集快照增加可为空的`industry`和`region`不可变元数据，新建问题集时必须明确填写；既有快照按未设置兼容读取；
- 实验运行不重复保存业务地区和行业，由其关联的问题集快照投影到目录响应和页面筛选；采集会话中的`CN_MAINLAND`等`session_conditions.region`继续表示技术运行地区，两者不得混用；
- 新问题集快照的内容哈希包含业务地区和行业；历史快照继续按旧哈希口径校验，避免迁移改写或证据漂移；
- 项目创建表单同时收集地区和行业，Owner或Admin可补充或修正现有项目的这两项元数据；更新使用版本号做并发保护；
- 项目、问题集和实验运行视图增加独立的地区、行业筛选；筛选只改变当前页面展示，不删除、不改写数据；
- 项目、问题集和运行等动态选择器改为可输入搜索的选择器，保留键盘操作与原有选中值；
- 问题集创建页提供行业、地区和生成数量，使用本地确定性模板一次生成5、10或20个问题；结果先写入可编辑文本区，保存前由用户确认；
- 生成器不调用外部AI，不声称自动生成内容来自真实用户问题或平台建议；生成来源以`industry-question-generator@1`记录在问题集快照来源元数据中；
- 生成问题的意图按模板记录；用户改写后无法匹配原模板的条目使用表单选择的默认意图，商业价值仍使用表单统一设置。

## 边界与取舍

- 第一版不建设行业字典后台、行政区划树、标签多选、全文检索服务或向量检索；
- 地区和行业均为最多80字的人工可读标签，页面提供常用建议但允许直接输入；
- 筛选在当前已加载目录中执行；问题集和运行达到需要服务端分页的规模后再单独立项；
- 不从问题文本、项目名称或历史回答中自动补齐地区和行业。

## 验收

- 新建和更新项目可保存地区、行业，未设置的历史项目可正常读取；
- 新建问题集必须包含地区、行业，旧快照不发生哈希漂移；
- 一键生成数量与选择一致，生成内容可编辑，保存后生成来源和模板意图可追溯；
- 项目、问题集、运行视图可分别按地区和行业筛选，并有清除筛选和无结果状态；
- 动态选择器可通过输入关键词定位，标签包含必要的名称、平台、时间或短ID；
- 运行的地区、行业与关联快照一致，采集地区代码仍独立显示；
- 契约、迁移、后端、前端、测试、OpenAPI与`pnpm verify`全部通过。
