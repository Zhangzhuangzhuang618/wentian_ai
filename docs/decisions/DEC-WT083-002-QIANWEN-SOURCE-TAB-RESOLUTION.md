# DEC-WT083-002 千问可见来源临时标签解析

> 状态：已接受  
> 日期：2026-08-26  
> 适用范围：千问 Web 浏览器扩展、可见来源 URL 采集、Chrome 权限

## 背景

后续真实页面核验表明，千问“参考来源”面板中的来源条目是可见、可点击的卡片。卡片没有公开`href`，但当前页面会在卡片公开`data-*`属性中提供来源序号、标题和HTTP(S) URL；用户点击卡片时仍会打开外部来源标签页。因此应优先读取当前可见卡片属性，临时来源标签只作为属性缺失时的回退。

## 决策

- 优先读取当前已展开、可见来源卡片公开属性中的`refer_num`、`title`、`url`或`ref_url`；
- 卡片没有合格外部URL时，才使用 Chrome `tabs` 权限执行临时标签回退；
- 每次回退点击卡片前建立一次 10 秒有效的临时监听；
- 只接受 `openerTabId` 等于当前千问标签页、且位于同一浏览器窗口的新标签页；
- 忽略千问站内地址、非 HTTP(S) 地址和其他标签页；
- 读取外部 URL 后立即关闭临时来源标签页，并重新激活原千问标签页；
- 不读取 Cookie、Web Storage、浏览历史、网络响应、页面私有状态或来源页正文；
- 任一来源卡片未打开、超时或数量不完整时失败关闭，本题不提交；
- 来源面板关闭失败不丢弃已经完整读取的证据；数量不完整仍失败关闭；
- 扩展版本升级为 `0.0.19`，页面签名和 Surface 版本保持不变。

## 权限说明

Chrome 对 `tabs` 权限可能显示宽泛的浏览数据提示。代码仅在可见来源卡片缺少公开URL、且用户已启动千问采集流程时，监听由当前千问页打开的临时来源标签页；不枚举既有标签页，不保存来源标签页标题或其他标签信息。

## 验收

- 非当前千问页打开的标签被忽略；
- 千问站内标签和非 HTTP(S) 地址不作为正式来源；
- 公开卡片属性可直接得到来源序号、标题和URL；
- 回退时，每个已解析来源标签读取 URL 后被关闭，原千问页恢复激活；
- 数量与面板声明一致后才提交；
- 自动化和权限静态检查通过；真实页面手动选择、提交、复核和排名闭环通过；验证码中断后的无干预整批续跑仍单独记录为平台限制。

## 对既有决策的影响

本决策只对千问可见来源解析增加受限的临时跨标签操作，局部取代 `DEC-WT074-001` 中“不跨标签页”的限制；连续提问仍不在多个 AI 标签页、账号或后台无人值守环境中编排。
