# DEC-WT080-001 采集页按问题聚合展示采样单元

> 状态：已接受  
> 日期：2026-08-26  
> 适用范围：问天独立版采集与复核工作台

## 背景

一次实验运行会按“问题数 × 每题采样次数”生成采样任务。当前页面把每个采样任务显示为一张同等层级的卡片，同一问题的第1次、第2次采样因而看起来像多个独立任务；整批采集中断后继续领取剩余采样时，这种展示也容易被误解为系统重新创建了任务。

任务数据本身没有重复创建：续接只领取原运行内尚未完成的采样任务，任务ID、运行ID和样本序号保持不变。

## 决策

- 采集与复核主列表按 `query_snapshot_item_id` 聚合，每个问题只显示一张主卡片；
- 主卡片显示该问题的采样完成度和各状态数量；
- 每次采样作为卡片内的明细行展示，保留领取、重新生成接入码、预览、确认和驳回操作；
- 存在待处理采样的问题默认展开，全部结束的问题默认收起，用户可手动展开；
- 运行摘要、运行选择器和创建区使用“问题”“次采样”描述数量，不再把采样次数笼统显示为“项任务”；
- 不合并、不删除、不迁移既有采样任务，不改变运行状态机、证据或统计口径。

## 边界

- 本次只改变前端分组与术语；
- 不新增数据库迁移、API字段或第三方依赖；
- 任务仍是服务端执行和审计的最小单元，前端分组不改变其身份。

## 验收

- 同一问题的多次采样只占一张主卡片；
- 卡片可展开查看每次采样的状态、短ID和既有操作；
- 中断续接后，剩余采样仍出现在原问题卡片和原运行中；
- 页面明确显示问题数、每题采样次数和总采样次数；
- 自动化测试和 `pnpm verify` 通过。
