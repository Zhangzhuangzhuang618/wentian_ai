# DEC-WT053-001 提名—引用重合度只读模型边界

> 状态：已接受  
> 日期：2026-08-23  
> 适用范围：WT-052单问题重合度的严格内部DTO

## 背景

WT-052已经固定单问题纯计算结果。若只在界面拼接分子、分母和集合，调用方可以改变固定K口径、隐藏不足K的有效集合大小，或加入因果性和内部抓取结论。

## 决策

- 新建独立草案契约`wentian-nomination-citation-overlap@0-draft`；
- 严格返回方法版本、问题身份、K、分子、固定分母、数值、两侧有效集合、交集和固定警告；
- 契约复算分母必须等于K、数值必须等于分子除以K、分子必须等于交集大小；
- 两侧数组必须唯一、已规范化且长度不超过K；
- 交集必须严格等于按提名侧顺序计算的实际交集；
- 额外字段失败关闭，不允许增加“内部抓取频率”“一致率”或因果结论；
- 当前不注册HTTP或OpenAPI，不声明运行可比性已经完成。

## 影响

- 调用方不能把有效集合大小当作替代分母；
- 手工构造的响应也不能用超过K的数组绕过适配器；
- 后续比较服务可以复用该DTO承载每题已通过门禁的计算结果。

## 排除方案

- 复用自述指标契约并静默加字段：混淆两种方法版本；
- 只校验比例范围：无法防止分母和集合被同步篡改；
- 现在发布比较路由：时间窗、排行榜和生产身份尚未获批。
