# DEC-WT068-001 豆包可见页面驱动与服务端预检

> 状态：已接受（开发与合成测试获准，生产启用待授权）  
> 日期：2026-08-24  
> 适用范围：豆包浏览器扩展、自动提问服务端预检

## 背景

`DEC-WT067-001`已经定义自动提问执行器门禁和驱动契约，但浏览器扩展仍只有用户手动选择回答的采集流程。项目所有者要求先完成开发和测试，并在上线前补齐外部平台授权。

## 决策

- 浏览器扩展新增可见页面自动提问模式，保留原有手动采集模式；
- 自动模式必须由用户在当前豆包聊天页主动点击启动，不做无人值守调度；
- 扩展必须先持一次性接入码向问天服务端执行预检，不能信任页面或接入码明文自行声明的自动化开关和授权状态；
- 服务端预检必须校验接入码签名、有效期、实例、项目、任务、用户、任务版本、任务状态、项目自动化开关、地区和部署侧授权配置；
- 可见网页驱动在生产环境只接受`written_permission`授权依据、非空证据编号和90天内的复核时间；`official_interface`不能用于放行网页驱动；
- 部署配置默认`production + none`，因此即使项目开关打开，未配置授权时仍失败关闭；
- 驱动只能操作当前`https://www.doubao.com/chat/`页面中的可见输入框、发送控件、回答区域和可见链接；不得读取Cookie、Web Storage、隐藏网络响应或账号凭证；
- 回答必须经过页面签名、可见性、生成结束和文本稳定判断；超时或结构不匹配时停止并提示改用手动选择；
- 自动采集完成后仍展示本地预览，并要求用户最终确认后才上传到问天；上传后继续进入`needs_review`；
- 合成DOM测试可以验证输入、候选选择、稳定判断和失败回退；没有授权时不对真实豆包页面执行自动提问。

## 代码边界

API组合层可以依赖豆包适配器以执行服务端预检；核心领域、应用、基础设施仍不得反向依赖适配器。浏览器扩展不直接获得部署侧授权证据，只接收一次性`ready`结果和当前任务问题。

## 验收

- 项目开关关闭、令牌过期、任务版本变化、生产授权缺失、复核超期或授权范围不匹配时不触发页面输入；
- 服务端预检成功后，合成页面驱动可输入当前任务问题、等待稳定回答、采集可见链接和截图并进入本地预览；
- 回答未完成、页面结构不匹配或超时均失败关闭，并保留手动选择入口；
- 扩展不新增Cookie、网络监听、持久存储或远程主机权限；
- `pnpm verify`通过。
