# DEC-WT055-001 配对运行24小时可比性门禁

> 状态：已接受  
> 日期：2026-08-23  
> 适用范围：消费端自然回答与信源自述配对运行  
> 批准依据：项目所有者于2026-08-23接受24小时建议

## 背景

批准基线要求提名—引用对照发生在同一问题、同一消费端产品、相近时间和匹配配置下，但没有定义“相近时间”的精确阈值，也没有定义按创建时间还是实际开始时间判断。

## 决策

- 使用两次运行各自的`startedAt`计算绝对时间差，不使用`createdAt`或`completedAt`；
- 时间差小于或等于24小时可通过时间门禁，超过24小时返回`not_comparable`；
- 两次运行都必须进入终态并具有有效`startedAt`和`completedAt`；
- 自述运行必须通过`pairedRunId`明确指向自然回答运行；
- scope、问题集快照、Surface版本、采集方式、计划样本数和全部会话条件必须一致；
- 自然回答运行按其页面搜索状态派生有效提名上下文，并与自述运行的提名上下文一致；
- 门禁返回确定性原因码，不满足条件时不得调用Top-K重合计算；
- 门禁只判断实验设计是否可直接对照，不替代样本可用性检查。终态为失败或取消时可通过结构与时间检查，但后续若没有足够正式样本，指标仍必须返回`not_available`。

## 边界

- 恰好24小时视为可比；
- 即使两次运行在同一天创建，只要实际开始时间相差超过24小时，仍不可比；
- 24小时之外的数据可以并列展示，但不能生成直接重合指标。

## 排除方案

- 使用自然日或日历日期：受时区和跨午夜影响，无法稳定复算；
- 使用创建时间：排队等待会掩盖实际实验间隔；
- 自动放宽到7天：页面、排序和搜索结果漂移风险更高，且未获批准。
