# DEC-WT005-002 豆包用户在场自动化选择

> 状态：开发方式已确认，生产启用未批准  
> 决策日期：2026-08-21  
> 用户选择：采用第一种自动化

## 决策

豆包消费端观察采用用户在场的 `browser_assisted`：用户自行登录豆包、逐题完成提问，并主动点击问天采集按钮；问天只读取当前可见回答、可见引用、白名单页面元数据和当前视口截图，生成本地预览，用户确认后才上传暂存观察包。

## 固定禁止项

- 不自动登录或保存豆包账号凭证；
- 不自动提交问题、批量刷新或跨账号轮换；
- 不读取Cookie、localStorage、Authorization、隐藏网络响应或内部API；
- 不读取其他标签页、其他对话或当前页面不可见内容；
- 不在回答生成中、来源面板加载中或页面签名未知时继续采集；
- 不绕过用户预览和问天最终人工确认。

## 失败关闭

豆包页面结构动态变化。页面签名不能匹配时，适配器不得猜测DOM选择器，必须暂停浏览器辅助采集，并向用户提供 `manual_import` 回退路径。

## 状态影响

该决策批准WT-006开发，不等于豆包Surface可以从 `draft` 转为 `active`。截图和回答保留期、DOM策略、条款责任人及生产启用结论仍由WT-005门禁控制。
