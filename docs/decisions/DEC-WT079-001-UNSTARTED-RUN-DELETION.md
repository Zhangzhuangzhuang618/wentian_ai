# DEC-WT079-001 未开始运行删除

> 状态：已接受  
> 日期：2026-08-26  
> 适用范围：问天独立版实验记录与消费端观察运行

## 背景

用户可能因问题集选择错误或重复操作创建尚未开始的实验运行。现有系统只有项目级删除；要移除一条误建运行只能删除整个项目，不符合最小影响原则。

## 决策

- 第一版只允许实例 Owner 且同时为项目 Owner 的用户删除状态为`queued`，且其全部任务仍为`waiting_user`的运行；
- 删除前由界面展示运行名称、计划任务数和不可恢复提示，并要求用户再次确认；
- 删除请求必须使用当前登录会话、CSRF校验和项目访问校验；非Owner拒绝执行；
- 删除在PostgreSQL事务中锁定项目、运行和任务后原子完成，运行任务通过现有外键级联清理；
- 即使任务状态异常地仍为`waiting_user`，只要已存在采集包或确认记录，也必须拒绝删除；
- 已领取、采集中、待复核、已确认、已拒绝、已过期、已取消或已结束的运行均不得删除；
- 删除运行不删除问题集快照，不影响同项目其他运行；
- 第一版不提供已开始运行的硬删除、回收站或批量删除。

## 理由

未开始运行没有回答、截图、正式信源事件或排名事实，删除它不会改变证据口径。把删除扩展到已开始运行会涉及对象存储、正式来源事件、审计和指标重算，需要单独的数据生命周期设计。

## 验收

- Owner可以删除误建且未开始的运行；
- 删除后实验记录、运行选择器和采集任务列表同步移除该运行；
- 已开始或已完成运行返回明确拒绝，不删除任何数据；
- 跨项目、非Owner、无CSRF请求失败关闭；
- `pnpm verify`通过。
