# DEC-WT048-001 消费端自述单运行指标上下文

> 状态：已接受  
> 日期：2026-08-23  
> 适用范围：消费端自述运行的内部按需指标报告

## 背景

WT-035严格DTO只描述纯领域指标，没有运行、问题集来源、采集方式和Surface身份。单运行查询若只返回领域结果，调用方无法区分同一快照的不同运行，也无法审计消费端采集上下文。

## 决策

- 内部单运行报告在WT-034领域结果之外附带run ID；
- 附带问题集来源和GEO连接器契约版本，并强制两者成对；
- 固定`experimentKind=source_nomination`；
- 附带采集方式、提名上下文、Surface版本和Surface code；
- 所有样本必须与运行的单一提名上下文一致；
- 按需服务先做scope门禁，再调用批次构建器并复核返回身份；
- 不修改WT-035现有纯指标DTO，不注册公共路由。

## 影响

- 单运行报告具备可审计消费端上下文，仍复用同一纯指标函数；
- 同一批次不能混合unaided、search-assisted或surface-unknown样本；
- 后续如公开运行级DTO，必须新增严格契约而不是静默扩展WT-035。

## 排除方案

- 只返回纯领域报告：缺少运行和采集上下文；
- 修改已存在的WT-035 DTO并直接发布：当前无公共路由批准；
- 允许样本按自身上下文重新分组：会掩盖运行级配置漂移。
