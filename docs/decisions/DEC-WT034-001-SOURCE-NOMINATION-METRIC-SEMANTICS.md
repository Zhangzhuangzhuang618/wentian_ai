# DEC-WT034-001 信源自述指标实现语义

> 状态：已接受  
> 日期：2026-08-22  
> 适用范围：信源自述提名率、首位提名率、提名份额和稳定度纯领域计算  
> 批准依据：`CHG-VIS-002`第5节信源自述指标

## 背景

批准基线已经定义信源自述指标公式，但实现仍需固定解析确认、重复域名、顺序缺失、上下文隔离和空集合的处理方式。若这些语义留给调用方，前端或不同查询服务可能得到不同分母。

## 决策

- 只有`schema_validated`和`human_confirmed`样本进入指标分母；`needs_review`与`rejected`只进入排除计数；
- 输入必须显式覆盖全部成功响应样本，避免未表示的成功样本静默退出分母；
- `unaided`、`search_assisted`和`surface_unknown`分别形成指标组，不生成跨上下文合并率；
- 同一样本重复提名同一域名时，提名率只按该样本计一次；提名份额按实际提名事件计数；
- 提名顺序必须全部存在或全部缺失；存在时必须是从1开始且无重复、无缺口的序列；
- 首位提名率分母只包含具有有效顺序且至少有一项提名的样本；没有任何有效顺序时该指标返回`not_available`；
- 提名稳定度使用同一问题不同已确认样本的域名集合Jaccard；两个集合都为空时记为“无提名样本对”，不设为1；
- 每个样本最多10个显式提名事件；本函数不解析回答正文，也不访问网页。

## 影响

- 提名率描述模型声明的参考偏好，不能改名为抓取频率或真实引用倾向；
- 解析未确认样本不会污染指标；
- 重复提名可以影响事件份额，但不能重复增加样本提名率；
- 不同搜索上下文无法因查询便利被默认合并；
- 后续DTO和查询服务必须复用本纯函数，而不是重写公式。

## 排除方案

- 把`needs_review`纳入分母：其结构仍未得到确认；
- 从正文出现顺序推断首位：基线明确禁止猜测；
- 空—空集合按Jaccard 1处理：会把“没有任何提名”误报为高度稳定；
- 对重复域名一律删除事件：会改变提名份额的事件口径；
- 直接计算提名—引用重合：配对运行和可比性校验尚未实现。
