# DEC-WT060-001 本地会话与项目访问边界

## 状态

已接受，日期：2026-08-23。

## 背景

WT-059已建立本地用户、一次性Owner、会话、项目和成员表，但尚无可使用的本地登录和项目设置接口。问天独立版不能依赖GEO身份，也不能把浏览器可读令牌或客户端scope参数当作授权依据。

## 决策

- 本地登录使用Owner初始化时保存的`scrypt`密码摘要；登录失败不区分账号不存在、密码错误或账号禁用；
- 成功登录生成256位随机会话令牌，数据库只保存SHA-256摘要；
- 浏览器会话只通过`HttpOnly + SameSite=Strict` Cookie传递；生产HTTPS部署必须启用`Secure`；
- CSRF令牌由实例级高熵会话密钥和当前会话令牌通过HMAC派生，不写入数据库；
- 所有修改操作同时校验第一方Origin和`X-Wentian-CSRF-Token`；
- 服务端从会话用户及`scope_memberships`派生项目允许集合，客户端scope ID只用于选择；
- 项目创建在一个事务中写入项目、Owner成员关系和默认关闭的消费端自动化设置；
- 自动化开关使用乐观锁版本更新，地区和治理策略版本不能由普通请求修改；
- 当前不提供公开注册、记住登录、第三方身份或跨组织能力。

## 后果

问天可以在GEO完全不可用时完成本地登录、项目创建和项目级自动化选择。后续真实采集API必须复用该会话和scope授权，不得自行信任请求体中的用户或项目身份。
