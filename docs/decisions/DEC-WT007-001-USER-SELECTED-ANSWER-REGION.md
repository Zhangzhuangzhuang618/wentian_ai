# DEC-WT007-001 用户选择回答区域的采集方式

> 状态：已确认用于本地原型  
> 决策日期：2026-08-21  
> 适用任务：WT-007  
> Surface状态：`draft`

## 背景

豆包登录页和回答页可以正常打开，用户也能自行完成登录与提问。但在本次实测中，应用内浏览器对豆包的可见DOM、截图、轻量定位器和隔离剪贴板读取均持续超时，无法形成可验证的稳定页面选择器。继续猜测CSS类名或内部结构不符合失败关闭要求。

## 决策

WT-007不依赖固定豆包DOM选择器，改用用户选择回答区域：

1. 用户自行登录并完成提问；
2. 用户点击问天扩展图标；
3. 扩展仅在该次用户触发后获得当前标签页临时权限；
4. 用户在页面上选择回答区域；
5. 扩展提取所选区域的渲染文本和实际HTTP(S)链接；
6. 扩展临时截取当前视口，只保留所选区域在当前视口内的截图；
7. 本地预览后，由用户确认并导出本地JSON；
8. 当前原型不上传问天API，也不激活豆包Surface。

## 信源语义

- 所选区域内实际存在且可见的HTTP(S)链接才进入 `visible_citations` 候选；
- 回答文本中“参考来源：买购网”等名称只进入 `source_mention_hints`，固定标记为 `unverified_text_mention`；
- `source_mention_hints` 仅服务本地预览和人工复核，不写成 `candidate`、`cited` 或 `nominated` 来源事件；
- 不从名称猜测域名，不补造URL，不访问引用页面正文。

## 权限与禁止项

扩展只申请 `activeTab` 和 `scripting`。不申请持久host权限、Cookie、存储、下载、网络监听或跨标签页权限；不实现登录、自动提问、批量运行、隐藏请求读取或API上传。

## 影响

该方式是对已批准 `browser_assisted` 的具体实现，不改变CHG-VIS-002的产品和证据语义。页面Adapter仍为 `draft/unverified`；只有完成真实Chrome安装演练、截图与保留策略、API任务绑定和条款门禁后，才可另行评审是否激活。
