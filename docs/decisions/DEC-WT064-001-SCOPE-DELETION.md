# DEC-WT064-001 项目删除与跨存储清理

## 状态

已接受，日期：2026-08-23。

## 决策

- 第一版只有问天实例 Owner 且同时为项目 Owner 的用户可以删除项目；
- 删除请求必须重新验证当前本地账号密码，并要求输入完全一致的项目标识和当前版本；
- 接受删除后项目立即进入 `deleting`，停止新运行、上传和业务写入，前台不提供回收站；
- 删除服务先撤销该项目的一次性采集凭据和外部连接，再清理对象存储前缀与 PostgreSQL 业务数据；
- 删除作业保存在项目之外，失败可以由同一 Owner 重试，成功后仅保留不含回答正文的最小审计记录；
- GEO解绑本身不删除问天项目；问天项目删除必须先撤销对应binding；
- 对象、数据库和备份中的项目残留最长30天内清完，已删除项目不得通过普通产品流程恢复；
- 第一版沿用部署主机维护任务，不为项目删除单独引入 Redis 或常驻Worker。

## 后果

项目删除是显式、不可逆的问天本地动作。跨存储失败不会伪装成删除成功，删除作业可重试并可审计。
