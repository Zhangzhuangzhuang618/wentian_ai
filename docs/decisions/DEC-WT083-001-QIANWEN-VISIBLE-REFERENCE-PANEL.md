# DEC-WT083-001 千问可见来源面板采集

> 状态：已接受  
> 日期：2026-08-26  
> 适用范围：千问 Web 页面驱动、证据采集、Surface版本与信源统计

> 补充决策：[`DEC-WT083-002`](./DEC-WT083-002-QIANWEN-SOURCE-TAB-RESOLUTION.md)

## 背景

WT-082真实页面烟测证明千问会把正式来源放在回答附近的“`N篇来源`”入口中。展开后页面显示“`参考来源 (N)`”及可点击的来源条目。首版只读取回答区域内链接，导致回答、截图和回传成功，但正式信源为零。

## 决策

- 只在用户当前可见的千问回答附近识别“`N篇来源`”或“`参考来源 (N)`”；
- 展开可见面板，读取页面公开呈现的HTTP(S)链接，完整读取后收起面板；
- 对不暴露URL属性、但会打开外部来源页的可见卡片，按`DEC-WT083-002`通过临时来源标签解析真实URL；
- 页面声明N条但未读到N条链接时失败关闭，不提交不完整证据；
- 不读取Cookie、Web Storage、隐藏接口、网络响应或页面私有状态；
- 页面签名升级为`qianwen-web-signature@2-visible-reference-panel`；
- 适配器升级为`qianwen-web@2-visible-reference-panel`；
- 新增`0009`Surface版本迁移：旧千问版本转为`suspended`，历史运行继续引用旧版本，新运行绑定新版本。

## 验收

- 千问“`N篇来源`”与“`参考来源 (N)`”数量识别有界且可测试；
- 来源面板完整展开、提取和收起，缺项时不提交；
- 问天预览显示千问正式链接，确认后可进入域名排名；
- 全量门禁、迁移、服务健康检查及真实页面烟测通过。

## 取舍

不把面板中的纯文本域名或媒体名推断成正式URL。只有页面公开呈现、可由浏览器解析的HTTP(S)目标进入正式引用。
