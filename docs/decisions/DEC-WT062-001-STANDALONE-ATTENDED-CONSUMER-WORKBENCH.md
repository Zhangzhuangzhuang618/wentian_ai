# DEC-WT062-001 独立版消费端实验工作台

## 状态

已接受，日期：2026-08-23。

## 决策

- 独立版Web界面覆盖项目、问题集、运行、任务领取、最终复核、信源推荐复核、累计排名和配对对照；
- 豆包扩展使用一次性接入码直接提交本机问天，不保存接入码，不接受非本机API地址；
- 自然回答实验使用原问题；信源推荐实验由服务端固定派生提示词，要求前10个域名、信息类型和理由；
- 信源推荐回答中的域名先进入`needs_review`，人工确认后才创建正式`nominated`事件；
- 自然回答只创建`cited`事件，信源推荐只创建`nominated`事件，两个角色不得混写；
- 对照使用正式事件，不把AI自述当成真实内部抓取统计；
- Web界面打开自动化开关只记录项目设置，不绕过外部授权门禁。

## 后果

问天可以作为独立系统完成豆包用户在场实验，不需要GEO连接器。生产自动提问仍未获得外部授权，不能由工作台或开关状态推导为已启用。
