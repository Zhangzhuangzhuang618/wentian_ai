# DEC-WT035-001 信源自述指标只读模型边界

> 状态：已接受  
> 日期：2026-08-22  
> 适用范围：信源自述指标snake_case响应草案  
> 批准依据：`CHG-VIS-002`信源自述口径、质量标记和项目所有者持续推进授权

## 背景

WT-034已经形成纯领域报告。若直接把领域对象作为API返回，调用方无法依赖稳定字段命名，比例、事件份额、上下文隔离和不可用状态也缺少运行时复核。当前又不具备发布公共路由的生产基础。

## 决策

- 新建`wentian-source-nomination-metrics@0-draft`严格只读Schema；
- DTO保留每个比例的分子、分母和值，不只返回百分比；
- 每个`nomination_context`单独成组，Schema拒绝重复上下文组；
- Schema复核验证方式计数、事件份额、首位提名覆盖、稳定度和顶层样本覆盖；
- 可用与不可用状态互斥，无验证样本时不返回零指标；
- 固定输出“自述提名不是可观察抓取或引用”的警告；
- 契约不注册HTTP路由，不进入现有消费端OpenAPI草案。

## 影响

- 领域公式与传输契约分离，DTO适配不重新计算指标；
- 伪造比例、合并上下文或漏报成功样本会在边界被拒绝；
- `@0-draft`不代表公共兼容承诺；
- 后续查询服务可以复用该DTO，但必须先建立运行和证据来源。

## 排除方案

- 直接序列化领域对象：缺少运行时Schema和snake_case边界；
- 复用消费端引用指标DTO：会混淆提名与实际引用；
- 只返回比例值：无法复算分母和样本质量；
- 立即加入OpenAPI：尚无查询服务、Repository、生产身份和持久化。
