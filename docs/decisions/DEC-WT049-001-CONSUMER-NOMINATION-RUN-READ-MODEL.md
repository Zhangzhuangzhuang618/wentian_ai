# DEC-WT049-001 消费端自述运行级只读模型边界

> 状态：已接受  
> 日期：2026-08-23  
> 适用范围：消费端自述单运行指标的严格snake_case内部DTO

## 背景

WT-035纯指标DTO不包含运行和消费端上下文，WT-048内部报告已经补齐这些字段。若直接扩展WT-035现有契约版本，会把纯领域报告和单运行产品读模型混为同一兼容承诺。

## 决策

- 新建`wentian-consumer-source-nomination-run-metrics@0-draft`；
- 复用WT-035全部字段和可复算校验，不修改原契约；
- 增加run、问题集来源、GEO契约、实验类型、采集方式、提名上下文、Surface版本和Surface code；
- GEO来源与契约版本必须成对；
- 报告内所有指标组必须与运行提名上下文一致；
- DTO保持严格对象，拒绝内部抓取频率等额外结论字段；
- 契约仍不注册HTTP或OpenAPI。

## 影响

- 纯领域DTO与运行级DTO拥有独立草案版本；
- 运行级调用方可以审计采集和问题集来源；
- 原有比例、样本覆盖、不可用状态和警告继续由同一基础Schema复核。

## 排除方案

- 静默增加WT-035字段：破坏其纯指标边界；
- 只在UI拼接运行信息：传输层无法复核；
- 复制公式校验但不复用基础Schema：容易产生契约漂移；
- 立即发布公共路由：生产身份和持久化尚未获批。
