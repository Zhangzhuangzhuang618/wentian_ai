# DEC-WT078-001 运行问题集选择与当前运行识别

> 状态：已接受  
> 日期：2026-08-25  
> 适用范围：问天独立版问题集、运行创建、采集与复核工作台

## 背景

用户保存新问题集后，运行表单继续保留此前选中的旧问题集。若用户直接创建运行，新运行会合法但意外地绑定旧问题集。采集页又只展示当前所选运行的任务，运行下拉框缺少题数、任务数和创建时间，容易把历史已完成运行误认为刚创建的运行。

数据库与任务隔离没有失效；问题出在前端没有把“刚保存的问题集”和“当前查看的运行”表达清楚。

## 决策

- 保存问题集成功后，运行表单必须自动选中服务端响应中的该问题集ID；
- 运行创建区必须在提交前展示问题集名称、题数、采样次数、计划任务数和新运行初始状态；
- 运行创建成功提示必须包含问题集名称、计划任务数和“待开始”状态；
- 运行选择器必须展示问题集、任务数、状态、创建时间和短运行ID；
- 采集与复核区必须显示当前运行摘要，并明确下方仅展示当前运行任务，历史运行未删除且可从运行选择器切换；
- 不自动删除误建运行，不改变已有运行、任务、证据或指标数据。

## 边界

- 不修改问题集不可变语义、运行状态机、任务归属、证据语义或指标口径；
- 不新增数据库迁移、API字段或第三方依赖；
- 前端选择仍以服务端返回的问题集ID和运行ID为事实依据。

## 验收

- 新保存问题集后，运行表单选中该问题集而非此前问题集；
- 创建前摘要与实际请求的问题集ID和计划任务数一致；
- 新运行创建后，采集页选中新运行并显示“待开始”；
- 切换历史运行后，只显示该运行任务，同时明确历史数据没有被覆盖；
- `pnpm verify`通过，并完成浏览器实机验证。
