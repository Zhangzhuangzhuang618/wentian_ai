# DEC-WT058-001 豆包自动化开关与消费端数据治理

> 状态：产品规则已接受，豆包生产自动化授权未满足  
> 日期：2026-08-23  
> 适用范围：豆包消费端观察和独立版默认治理策略  
> 批准依据：项目所有者于2026-08-23确认自动化开关、保留期、地区和责任人按建议执行

## 背景

DEC-WT005-002只允许用户在场采集。项目所有者现批准增加默认关闭的自动化开关：关闭时继续使用用户自行登录、提问和主动采集；打开后允许系统自动提交问题、等待回答并采集可见结果。

产品批准不能替代外部平台授权。2026-08-23复核的[豆包用户协议](https://www.doubao.com/legal/terms)仍对未经书面许可的数据复制、读取、抓取、模拟下载、插件工具和商业使用设置限制。因此自动化能力必须同时受项目开关和生产授权门禁约束。

## 自动化决策

- 项目自动化开关默认`false`；未显式开启时一律走`attended`；
- 开关关闭时继续要求用户自行登录、提交问题、点击采集、本地预览和最终复核；
- 开关打开后，合成测试环境可执行自动提交、等待和采集，以便研发验证；
- 生产环境只有同时满足以下条件才能执行自动化：Surface为`active`、适配器明确支持、执行地区获准、存在适用于该用途的官方接口或平台书面许可及证据编号；
- 缺少任一生产门禁时返回阻断原因，不静默回退为自动化，也不把内部产品批准记作平台授权；
- 无论哪种模式，都不得自动登录、保存凭证、绕过验证码、读取Cookie/localStorage/Authorization或隐藏网络接口；
- 自动化采集仍进入`needs_review`，人工确认后才进入默认指标；
- 页面签名变化、授权到期或条款复核超过90天时应暂停生产自动化。

本决策补充并部分取代DEC-WT005-002中的“永不自动提交问题”，但保留其账号、隐藏数据、证据复核和失败关闭限制。

## 默认数据保留

| 数据                         | 默认策略                   |
| ---------------------------- | -------------------------- |
| 待复核暂存包                 | 24小时；超时清除           |
| 已拒绝暂存证据               | 立即清除                   |
| 当前页面/选区截图            | 确认后30天                 |
| 已确认回答正文               | 确认后180天                |
| 已确认可见引用与白名单元数据 | 确认后180天                |
| 脱敏DOM                      | 第一版关闭，不采集、不保存 |
| 正式信源事件与派生指标       | 保留至scope删除            |
| scope删除后的残留清理        | 最长30天内完成             |

保留期到期后，原始证据不可用于重新复核；正式信源事件只保留必要的规范URL/域名和审计字段，不保留第三方网页正文。

## 地区与责任人

- 第一版允许使用和保存数据的地区固定为中国大陆；
- 项目Owner负责确认业务目的、被测账号和内容使用权限，并决定是否开启项目自动化；
- 系统管理员负责存储区域、清除任务、备份生命周期和删除审计；
- 豆包条款和生产自动化授权由项目Owner与合规责任人共同复核，最长每90天一次；
- 未指定责任人、越区执行或证据过期时失败关闭。

## 状态影响

- 豆包适配器继续保持`draft`，生产授权依据为`none`；
- 自动化实现只能先进入合成测试和受门禁的控制平面；
- 本决策不批准真实豆包网页的生产自动执行，不把`doubao_web`发布为`active`。
