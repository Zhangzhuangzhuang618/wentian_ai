# DEC-WT076-001 豆包可见参考资料面板采集

> 状态：已接受  
> 日期：2026-08-25  
> 适用范围：豆包浏览器扩展、消费端观察证据、自然回答信源排名

## 背景

豆包当前页面把“搜索 4 个关键词，参考 22 篇资料”等入口与回答正文分开渲染。旧版扩展只读取所选回答区域内的`a[href]`，因此即使用户能展开并看到资料链接，上传结果仍可能是0条正式信源。已完成运行中的回答正文可以保留，但不能据此补造历史引用。

## 决策

- 回答稳定后，扩展先冻结当前回答正文，再查找当前回答内部或附近可见的“参考 N 篇资料”入口；
- 扩展点击该入口，只读取展开后新增显示在当前页面上的HTTP(S)链接，并在读取后把面板恢复为收起状态；
- 面板声明N篇资料时，必须观察到完整的N条可见链接才允许继续生成采集载荷；少于N条、入口失效或面板无法恢复时均失败关闭，本题不提交；
- 如果当前回答没有“参考 N 篇资料”入口，允许以0条面板信源继续，回答区域内原本可见的正式链接仍正常采集；
- 面板链接与回答区域内链接合并后按最终URL去重，并保留观察顺序；
- 只有真实可见链接属于正式引用。回答文字中的媒体名、网站名、域名或“参考来源”说明继续作为非引用提示，不进入正式信源排名；
- 扩展不得读取Cookie、Web Storage、隐藏网络响应、页面脚本状态或账号凭证，也不新增对应权限；
- 已确认的0信源历史结果不回填、不改写。需要在新版扩展下重新运行实验，才能产生可比较的新证据；
- 页面签名升级为`doubao-web-signature@6-visible-reference-panel`，扩展版本升级为`0.0.10`。

## 取舍

以页面显示数量作为完整性门槛会在豆包页面结构变化、链接懒加载失败或入口不可点击时暂停整批采集，但它能防止“页面明示有来源、问天却记录0来源”的静默错误。第一版不引入网络拦截、隐藏状态解析、滚动抓取或历史数据修复。

## 验收

- 当前豆包页面显示“参考 N 篇资料”时，预览中的正式可见链接数量为N；
- 面板打开前后的其他页面链接不会被误计入当前回答；
- 面板已展开或默认收起两种状态都能完成读取，并在结束后保持收起；
- 只读取到部分链接时显示明确错误，单题不上传、整批暂停；
- 没有参考资料入口的回答仍可正常采集并明确为0条面板信源；
- 自动模式和手动选择模式使用同一套参考资料读取逻辑；
- 既有确认数据不被改写；
- 页面逻辑测试、全量`pnpm verify`和已登录豆包页面预览烟测通过。
