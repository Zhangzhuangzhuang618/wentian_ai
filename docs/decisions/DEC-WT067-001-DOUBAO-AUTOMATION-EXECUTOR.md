# DEC-WT067-001 豆包生产自动提问执行器边界

> 状态：已接受（开发与测试获准，生产授权待上线前补齐）  
> 日期：2026-08-23  
> 适用范围：豆包消费端自动提问执行器

## 背景

项目所有者已确认继续开发和测试豆包自动提问能力，并承诺在上线前补齐适用于该用途的平台授权。该确认允许实现生产执行器边界和合成验证，但不等于已经取得豆包官方接口许可或书面许可。

`DEC-WT058-001`已经规定项目开关、地区、授权依据和人工复核门禁。本决策补充执行器的代码边界，不降低这些门禁。

## 决策

- 自动化开关未显式打开时，执行器返回`attended_required`，不得调用页面驱动；
- 合成环境可以使用替代驱动验证自动提交、等待和可见结果采集链路；
- 生产环境必须同时具备与驱动类型一致的授权依据和非空授权证据编号；官方接口驱动要求`official_interface`，可见网页驱动要求`written_permission`，两者不能互相替代；
- 授权事实必须来自服务端部署配置，不接受浏览器页面或普通任务请求自行声明；
- 页面驱动只能提交当前任务问题，并读取豆包页面中用户可见的回答、链接、页面标题和截图；
- 执行器不得登录账号、保存凭证、处理验证码、读取Cookie/localStorage/Authorization或隐藏网络响应；
- 页面来源必须严格为`https://www.doubao.com/chat/`，页面签名、完成状态或输出结构不匹配时失败关闭；
- 自动采集结果固定为`needs_review`，不能自动确认、不能直接进入默认指标；
- 生产页面驱动在授权证据接入和实机选择器烟测完成前不得启用。

## 与既有基线的关系

本决策仅替代`ADR-CHG-VIS-002`和`DEC-WT058-001`中“不得开发自动提问执行器”的范围限制；生产启用条件、禁止自动登录、可见数据边界和人工复核要求继续有效。用户的项目内批准不能替代外部平台授权。

## 验收

- 默认关闭、缺授权、缺证据、越区和授权范围不匹配均不调用驱动；
- 授权门禁满足时可调用替代驱动并产出`needs_review`结果；
- 非豆包页面、未完成回答、非法引用和非法截图失败关闭；
- 生产授权缺失时，即使项目开关打开也不能执行；
- `pnpm verify`通过。
