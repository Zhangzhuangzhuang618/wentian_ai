# WT-079 未开始运行删除

> 状态：已完成  
> 前置决策：[`DEC-WT079-001`](../decisions/DEC-WT079-001-UNSTARTED-RUN-DELETION.md)

## 目标

在实验记录中提供删除误建运行的入口，只清理从未开始且没有采集结果的运行。

## 实现范围

- PostgreSQL事务锁、证据存在性校验与运行删除；
- 独立版Owner鉴权、CSRF保护和HTTP删除接口；
- 实验记录二次确认、删除按钮和删除后选择状态恢复；
- 接口、仓储、静态页面和回归测试；
- 独立版Zod响应契约与任务文档同步；现有不可执行OpenAPI草案仍只描述早期消费端观察契约，不伪装为本地运行管理接口文档。

## 完成标准

- [x] 只有`queued`且全部任务为`waiting_user`、不存在采集包或确认记录的运行可删除；
- [x] 非Owner、跨项目、已开始和已完成运行均失败关闭；
- [x] 删除不影响问题集和其他运行；
- [x] 当前选中运行被删除后页面不会保留失效选择；
- [x] `pnpm verify`通过。
