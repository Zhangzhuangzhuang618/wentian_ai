# WT-076 豆包可见参考资料面板采集

> 状态：进行中  
> 决策：[`DEC-WT076-001`](../decisions/DEC-WT076-001-DOUBAO-REFERENCE-PANEL-CAPTURE.md)  
> 前置任务：[`WT-074`](./WT-074-CONTINUOUS-CAPTURE-BATCH.md)

## 目标

修复豆包回答有可见参考资料、问天却记录0条正式信源的问题，让自动和手动采集都读取当前回答的完整可见参考资料链接。

## 实现范围

- 识别“搜索 N 个关键词，参考 M 篇资料”和“参考 M 篇资料”入口；
- 绑定当前回答附近的入口，避免读取其他历史回答的资料；
- 通过面板展开前后的可见链接差异提取本次资料；
- 以页面声明数量作为完整性门槛，读取不完整时失败关闭；
- 读取完成后收起面板；
- 与回答正文内的可见链接合并并统一去重；
- 自动模式、整批模式和手动选择模式复用同一逻辑；
- 升级扩展版本和页面签名，更新使用说明与决策记录。

## 明确不做

- 不读取隐藏网络响应、Cookie、Web Storage或账号凭证；
- 不把回答里的网站名称、域名文字或来源说明升级为正式引用；
- 不修改或回填已确认的历史0信源结果；
- 不新增数据库迁移、后台任务或扩展权限；
- 不在第一版处理超过100条的单个参考资料面板。
