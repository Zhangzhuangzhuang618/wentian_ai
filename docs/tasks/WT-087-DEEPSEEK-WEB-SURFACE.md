# WT-087 接入 DeepSeek Web 消费端观察

> 状态：开发、合成验证、本地部署与真实页面核心结构核验完成；扩展端回传和自动刷新待 Chrome 烟测
> 关联决策：[`DEC-WT087-001`](../decisions/DEC-WT087-001-DEEPSEEK-WEB-SURFACE.md)
> 前置任务：[`WT-086`](./WT-086-LARGE-DYNAMIC-SELECTOR.md)

## 目标

在不改变人工复核和正式统计边界的前提下，让问天可创建、领取、采集和复核 DeepSeek Web 运行，并支持单题与整批可见页面编排。

## 实现范围

- 注册`deepseek_web` Surface及`0011`迁移；
- 增加运行观察对象选项和平台显示名称；
- 增加 DeepSeek 官方页面白名单、草稿契约和独立页面签名；
- 自动化预检按运行 Surface 读取 DeepSeek 独立部署门禁；
- 复用单题、整批领取、输入、发送、等待稳定和上传流程；
- 首版仅采集回答区真实可见 HTTP(S) 链接、回答正文和截图；
- 补充 Surface、页面路径、输入占位、新对话、预检、迁移和静态页面测试；
- 更新扩展说明和独立部署配置。

## 明确不做

- 不自动登录，不处理验证码或滑块；
- 不读取 Cookie、Web Storage、隐藏接口、网络响应或账号凭证；
- 不推断未显示的信源，不把纯文本媒体名或域名计作正式引用；
- 不声明已支持 DeepSeek 独立信源面板；
- 不改写既有豆包或千问数据；
- 不在缺少生产书面许可时放行生产自动化。
