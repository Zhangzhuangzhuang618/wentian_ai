# WT-060 本地登录、项目与自动化设置

> 状态：已完成  
> 前置任务：[`WT-059`](./WT-059-STANDALONE-V1-FOUNDATION.md)  
> 前置决策：[`DEC-WT060-001`](../decisions/DEC-WT060-001-LOCAL-SESSION-AND-SCOPE-ACCESS.md)

## 目标

提供不依赖GEO的本地Owner登录、会话恢复、退出、项目创建/列表和默认关闭的消费端自动化设置API。

## 实现范围

- 本地密码校验和统一登录失败；
- 摘要化会话令牌、HttpOnly Cookie、同源和CSRF门禁；
- 从服务端成员关系派生scope允许集合；
- 项目、Owner成员和默认设置事务创建；
- 自动化设置读取及乐观锁更新；
- 严格请求/响应契约和64KiB JSON限制。

## 明确不做

- 不提供公开注册、找回密码或第三方登录；
- 不接触豆包账号、Cookie、Token或隐藏请求；
- 不把自动化开关等同于第三方平台授权；
- 本任务不提供完整Web UI。

## 完成标准

- [x] Owner可登录、恢复会话和退出；
- [x] 无会话、错Origin和错CSRF失败关闭；
- [x] 项目创建保持事务性且自动化默认关闭；
- [x] 跨scope访问隐藏资源；
- [x] Docker真实数据库链路通过；
- [x] `pnpm verify`通过。

## 完成记录
