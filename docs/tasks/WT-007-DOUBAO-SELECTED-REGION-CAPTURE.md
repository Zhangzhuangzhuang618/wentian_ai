# WT-007 豆包用户选择回答区域采集原型

> 状态：已完成本地安装与真实页面演练  
> 批准来源：项目所有者选择用户在场自动化并提供首个回答样本  
> 对应基线：`CHG-VIS-002`、`VIS-W02`  
> Surface状态：`draft`

## 目标

实现可在普通Chrome中本地加载的Manifest V3原型。用户点击扩展图标并选择回答区域后，扩展生成本地预览，明确区分回答正文、实际可见链接和未验证文本信源提示。

## 实现范围

- `activeTab + scripting`最小权限；
- 只允许 `https://www.doubao.com/chat/` 页面；
- 用户主动点击扩展图标后才注入；
- 用户选择回答区域，不依赖未验证的固定DOM选择器；
- 提取回答区域渲染文本和可见HTTP(S)链接；
- 从回答文本生成非引用的人工复核提示；
- 临时截取当前视口并裁剪为所选区域当前可见截图；
- 本地预览、重新选择、丢弃和最终确认；
- 确认后只导出本地draft JSON。

## 明确不做

- 不自动安装或发布扩展；
- 不自动登录、提问、刷新或切换对话；
- 不读取Cookie、Token、浏览器存储、隐藏网络响应或其他标签页；
- 不保存或上传DOM；
- 不调用问天API，不写数据库；
- 不将文本信源提示转换成来源事件；
- 不将豆包Adapter改为 `active`。
