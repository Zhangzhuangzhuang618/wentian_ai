# WT-005 首批消费端Surface门禁

> 状态：部分确认，条款门禁未通过  
> 优先级：当前最高  
> 对应基线：`CHG-VIS-002`、`VIS-W01`、`VIS-W02`

## 目标

确认首批消费端产品、允许采集方式和证据保留规则，以便继续实现现场人工录入；未经确认的产品配置保持 `draft`，不得激活。

## 待确认项

1. 首批支持的消费端产品及页面版本；已确认产品为豆包，首期目标为豆包网页版；
2. 采集自动化级别；已确认采用用户自行登录和提问、主动点击采集的 `browser_assisted`，禁止无人值守操作；
3. 当前页面截图的保留期；
4. 是否首期关闭脱敏DOM保存；如启用，需确认保留期和脱敏标准；
5. 可见回答、可见引用和白名单元数据的保留期；
6. 是否将所有API模型等价关系初始设为 `unknown`，仅提供 `query_only`并列观察；
7. 产品条款复核责任人、复核日期和允许地区。

## 建议的最小首期

- 先选择一个消费端产品；
- 只实现用户主动粘贴回答、录入可见引用并上传当前页面截图；
- 关闭DOM采集和浏览器扩展；
- 模型等价固定为 `unknown/query_only`；
- 未经最终人工确认的数据不进入默认指标。

## 已确认记录

- 首批产品：豆包；
- 暂定Surface标识：`doubao_web`；
- 当前状态：`draft`；
- 当前允许采集方式：空，等待条款门禁；
- 计划采集方式：用户在场的 `browser_assisted`；
- 资料核对：[豆包用户协议](https://www.doubao.com/legal/terms)、[豆包隐私政策](https://www.doubao.com/legal/privacy)；
- 详细判断：[DEC-WT005-001 豆包首批Surface选择](../decisions/DEC-WT005-001-DOUBAO-FIRST-SURFACE.md)。
- 自动化边界：[DEC-WT005-002 豆包用户在场自动化选择](../decisions/DEC-WT005-002-DOUBAO-ATTENDED-AUTOMATION.md)。

## 完成标准

- [ ] 七项待确认内容形成书面决策；首批产品已确认，其余待确认；
- [ ] 首批Surface配置可从 `draft`安全发布；
- [ ] 明确保留期、删除行为和责任人；
- [ ] 未批准的采集方式保持禁用；
- [ ] 为现场人工录入应用服务签发下一任务号。
