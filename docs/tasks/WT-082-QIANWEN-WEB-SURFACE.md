# WT-082 接入千问 Web 消费端观察

> 状态：主链路真实页面烟测完成，来源面板缺口转WT-083  
> 关联决策：[`DEC-WT082-001`](../decisions/DEC-WT082-001-QIANWEN-WEB-SURFACE.md)  
> 前置任务：[`WT-081`](./WT-081-CAPTURE-HEADER-LAYOUT-FIX.md)

## 目标

在不改变人工复核和正式统计边界的前提下，让问天可创建、领取、采集和复核千问 Web 运行，并支持单题与整批可见页面编排。

## 实现范围

- 注册`qianwen_web` Surface及`0008`迁移；
- 新增运行观察对象选择和平台标识；
- 扩展千问官网页面白名单、草稿契约和独立页面签名；
- 自动化预检按运行Surface选择独立门禁配置；
- 单题、整批领取和上传校验当前页面与任务Surface；
- 千问首版采集回答区域内可见链接、回答正文和截图；
- 补充契约、页面白名单、预检、迁移和静态资源测试；
- 更新扩展使用说明和独立部署配置。

## 明确不做

- 不读取千问Cookie、Web Storage、隐藏接口或账号凭证；
- 不自动登录、不处理验证码；
- 不推断未显示的来源，不把纯文本媒体名计作正式引用；
- 不改写既有豆包数据；
- 不在缺少生产书面许可时放行生产自动化。

## 完成标准

- [x] 千问运行可创建并显示正确平台；
- [x] 人工选择采集可生成千问草稿并提交复核；
- [x] 单题和整批预检返回千问独立页面签名；
- [x] 跨平台页面、草稿和任务组合失败关闭；
- [x] `pnpm verify`通过；
- [x] `0008`迁移、服务重建、健康检查通过；
- [x] 已登录千问完成新对话、发送、等待、截图、回传和自动刷新烟测；
- [ ] 正式来源面板提取转[`WT-083`](./WT-083-QIANWEN-VISIBLE-REFERENCE-PANEL.md)完成。
