# WT-084 目录元数据、可搜索选择器与行业问题生成

> 状态：已完成  
> 决策：[`DEC-WT084-001`](../decisions/DEC-WT084-001-CATALOG-METADATA-AND-QUESTION-GENERATION.md)  
> 前置任务：[`WT-080`](./WT-080-QUESTION-GROUPED-CAPTURE-VIEW.md)

## 目标

让项目、问题集和实验运行在数据增长后仍可快速查找，并降低行业观察问题集的首次创建成本。

## 实现范围

- 项目地区、行业字段、迁移、创建与版本化更新接口；
- 问题集快照地区、行业字段和历史哈希兼容；
- 运行目录的地区、行业投影；
- 项目、问题集、运行的地区与行业筛选；
- 项目、问题集、运行相关动态选择器的输入搜索；
- 本地确定性行业问题生成器、数量选择、可编辑预览和来源标记；
- 契约、OpenAPI、自动测试、迁移与部署验证。

## 明确不做

- 不接入外部大模型生成问题；
- 不自动推断或批量回填历史地区、行业；
- 不建设行业字典管理后台和行政区划树；
- 不增加全文检索引擎、缓存或服务端分页；
- 不改变正式信源、复核、排名和信源对照口径。
