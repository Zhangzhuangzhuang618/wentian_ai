# WT-074 豆包整批连续采集编排

> 状态：进行中  
> 决策：[`DEC-WT074-001`](../decisions/DEC-WT074-001-CONTINUOUS-CAPTURE-BATCH.md)  
> 前置任务：[`WT-073`](./WT-073-DOUBAO-EDITOR-STATE-SYNC.md)

## 目标

把逐题复制接入码的自动采集改造成一次启动、连续处理同一运行全部待采集任务的整批流程。

## 实现范围

- 两小时有效、绑定实例/项目/运行/用户/来源的HMAC整批令牌；
- 问天运行页“整批接入”入口、待处理数量、有效期和使用说明；
- 问天采集页前台每3秒自动同步当前运行，切回标签页时立即同步；
- 扩展整批领取协议及逐题自动预检；
- 豆包页连续新建对话、发送、等待、截图、提交和领取下一题；
- 扩展内进度、主动停止、失败暂停与继续；
- 自动提交后统一进入问天`needs_review`；
- 保留单题自动采集和手动采集流程。

## 明确不做

- 不新增Redis、任务队列或批次数据库表；
- 不持久保存整批接入码或豆包账号状态；
- 不跨AI页面、跨账号或后台无人值守运行；千问来源卡片按`DEC-WT083-002`仅允许临时打开来源页读取URL后关闭；
- 不绕过验证码、页面门禁或生产授权；
- 不自动确认问天中的正式观察结果。

## 完成标准

- [x] 问天可为有待采集任务的运行生成整批接入码；
- [x] 扩展可凭整批码领取下一题并执行单题预检；
- [x] 每题成功上传后自动继续下一题；
- [x] 运行要求新对话时可见页面驱动会显式新建对话；
- [x] 支持停止、重试和完成进度；
- [x] 问天采集页可自动显示扩展提交后的最新任务状态；
- [x] 单题和手动采集没有被移除；
- [x] 契约、令牌、后台脚本和静态页面测试通过；
- [x] 在真实豆包登录页完成至少两题连续烟测；
- [ ] 用户确认整批交互可用。
