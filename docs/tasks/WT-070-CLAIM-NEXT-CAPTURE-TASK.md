# WT-070 一键领取下一条采集任务

> 状态：已完成  
> 前置任务：[`WT-069`](./WT-069-STANDALONE-WEB-UI-REFRESH.md)

## 目标

在“采集与复核”顶部增加一键领取入口，减少逐条查找等待任务的操作成本。

## 实现范围

- 自动领取当前所选运行中第一条“等待领取”任务；
- 显示当前剩余等待领取任务数量；
- 没有等待任务时禁用入口并显示明确状态；
- 保留每条任务原有的领取、重新生成接入码、确认和驳回操作；
- 继续复用单任务领取接口和 10 分钟一次性接入码。

## 不做

- 不批量领取全部任务；
- 不同时生成多个一次性接入码；
- 不改变任务状态机、接口或证据确认流程。

## 完成标准

- [x] 点击后只领取第一条等待任务；
- [x] 领取后展示问题和一次性接入码；
- [x] 剩余数量随任务状态更新；
- [x] 无可领取任务时按钮禁用；
- [x] `pnpm verify` 通过。
