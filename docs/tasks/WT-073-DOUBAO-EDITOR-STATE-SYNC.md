# WT-073 豆包编辑器状态同步修复

> 状态：已完成  
> 前置任务：[`WT-072`](./WT-072-DOUBAO-SUBMIT-CONTROL-COMPATIBILITY.md)

## 目标

修复问题文字已显示在豆包输入区，但豆包内部富文本编辑器状态未更新，导致发送按钮仍不可用的问题。

## 已确认事实

- 豆包当前公开页面资源将发送控件标记为`data-testid="chat_input_send_button"`；
- 豆包输入区可能使用富文本编辑器，直接修改`textContent`不足以更新内部状态；
- 模拟回车在该编辑器中只会产生换行，不能作为发送兜底。

## 实现范围

- 优先通过纯文本粘贴事件驱动富文本编辑器更新；
- 保留普通`textarea`的原生值设置与输入事件；
- 精确查找豆包当前发送控件；
- 移除模拟回车发送；
- 保留发送结果校验和人工回退。
