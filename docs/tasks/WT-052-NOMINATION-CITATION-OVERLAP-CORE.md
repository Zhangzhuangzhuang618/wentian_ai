# WT-052 提名—引用Top-K重合度纯计算核心

> 状态：已完成  
> 前置任务：[`WT-051`](./WT-051-UNSUPPORTED-INTERNAL-CLAIM-MARKER.md)  
> 前置决策：[`DEC-WT052-001`](../decisions/DEC-WT052-001-PREPARED-TOP-K-OVERLAP-BOUNDARY.md)  
> 对应基线：`NominationCitationOverlap@K(q)`  
> 发布状态：纯领域函数，无运行读取、排行榜聚合、HTTP或生产连接

## 目标

严格实现已批准的单问题Top-K集合重合公式，同时把尚未获批的跨样本排序语义留在调用边界之外。

## 实现

- 默认K=10，允许显式传入1至10；
- 两侧输入保持各自排名顺序并只截取前K；
- 返回交集数、固定K分母和值；
- 分别返回提名和引用的有效集合大小；
- 返回两侧实际Top-K集合与交集域名；
- 域名小写化并移除尾点，规范化后重复项失败关闭；
- 非域名形式、URL、非法K和空问题身份失败关闭；
- 返回固定非因果证据警告且结果不可变。

## 明确不做

- 不从运行或指标报告生成排行榜；
- 不选择跨样本聚合分数和并列排序规则；
- 不验证两次运行是否可比；
- 不聚合跨问题平均值；
- 不注册DTO、HTTP或持久化结果；
- 不访问Provider、消费端网页或GEO。

## 测试与自审

- 默认K=10的手工黄金集合得到`2/10`；
- 显式K只截取两侧各自前K；
- 集合不足K时仍保留固定分母并返回两侧有效大小；
- 空侧集合产生`0/K`而不是改变分母；
- 规范化、不可变输出、非法K、URL和重复域名失败关闭；
- 深度自审确认领域报告当前按域名字母排序，不能直接当作Top-K排行榜；
- 深度自审确认本函数必须位于可用性和可比性门禁之后。
