# WT-088 页面可见检索轨迹、洞察与 Excel 导出

> 状态：已完成
> 决策：[`DEC-WT088-001`](../decisions/DEC-WT088-001-VISIBLE-SEARCH-TRACE.md)
> 前置任务：[`WT-087`](./WT-087-DEEPSEEK-WEB-SURFACE.md)

## 目标

结构化保存消费端页面明确展示的检索词与资料数量，并在问天中提供可追溯的项目级分析、任务预览、运行下钻和 Excel 导出。

## 实现范围

- 扩展识别豆包页面可见检索摘要、检索词和声明数量；
- 草稿、提交、证据Artifact和不可变确认记录贯通；
- 项目级检索词洞察、运行与问题筛选、任务证据预览；
- 关键词汇总、明细、参考资料与口径说明四表Excel导出；
- 页面级信息架构调整，不新增实验步骤或前端框架；
- 契约、自动测试、文档、部署升级和真实页面烟测。

## 明确不做

- 不读取隐藏网络请求、Cookie、Token或平台内部日志；
- 不把页面可见检索词称为真实抓取词、抓取频率或模型隐藏偏好；
- 不反推历史记录，不做同义词聚类、搜索量或关键词价值评分；
- 不接入GEO数据库，不自动把导出结果写回GEO；
- 不抓取参考网页正文。
