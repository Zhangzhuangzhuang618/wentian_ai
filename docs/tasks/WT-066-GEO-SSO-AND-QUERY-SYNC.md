# WT-066 GEO一次性登录与问题集同步

> 状态：已完成  
> 前置任务：[`WT-065`](./WT-065-GEO-CONNECTOR-BINDING.md)

## 目标

实现60秒一次性登录票据和GEO问题集到问天不可变快照的同步闭环。

## 实现范围

- GEO外部身份、项目访问版本和受控项目成员关系；
- 一次性launch code、重放防护、受绑定会话和站内跳转白名单；
- GEO来源问题集的稳定排序、哈希、幂等和不可变保存；
- 解绑、角色变化和连接器吊销后的会话失效；
- 契约、接口和端到端测试。

## 完成标准

- [x] 票据60秒过期且只能消费一次；
- [x] 同一外部用户在不同项目的角色不串用；
- [x] 未知角色和外部跳转失败关闭；
- [x] 相同GEO修订幂等复用问天快照；
- [x] 同步后运行只引用问天snapshot ID；
- [x] `pnpm verify`通过。

## 完成记录

- 完成日期：2026-08-23；
