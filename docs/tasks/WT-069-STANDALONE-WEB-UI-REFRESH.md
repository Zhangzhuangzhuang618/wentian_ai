# WT-069 独立版 Web 工作台视觉与交互升级

> 状态：已完成  
> 前置任务：[`WT-068`](./WT-068-DOUBAO-VISIBLE-PAGE-DRIVER.md)

## 目标

在不改变现有接口、指标口径和安全边界的前提下，把独立版 Web 从功能验收界面升级为可正式使用的消费端实验工作台。

## 实现范围

- 建立问天独立版的品牌色、排版、间距、圆角、阴影和状态色规范；
- 重组登录页、项目侧栏、工作台页头和四步实验导航的信息层级；
- 保留问题集、运行、采集复核、排名对照、自动化、GEO 连接器和项目删除的既有功能；
- 明确区分“可见引用”和“AI 自述”两类证据的视觉语义；
- 补齐桌面、平板、移动端布局以及键盘焦点、禁用态和减弱动画支持；
- 完成静态资源、脚本语法和项目全量验证。

## 不做

- 不新增业务接口、数据表、指标或运行状态；
- 不引入前端框架、图标库、外部字体或远程图片；
- 不调整豆包自动化生产授权门禁；
- 不扩展为基线中尚未实现的完整五页签分析产品。

## 完成标准

- [x] 登录页和实验工作台使用统一的问天视觉系统；
- [x] 四步主流程在首屏中可识别，管理设置不抢占主任务层级；
- [x] 所有既有 DOM 标识和交互入口可继续使用；
- [x] 关键控件具备清晰的悬停、聚焦、禁用和危险状态；
- [x] 900px 和 600px 以下布局可用；
- [x] `pnpm verify` 通过。
