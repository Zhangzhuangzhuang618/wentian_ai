# WT-035 信源自述指标只读契约

> 状态：已完成  
> 前置任务：[`WT-034`](./WT-034-SOURCE-NOMINATION-METRICS.md)  
> 前置决策：[`DEC-WT035-001`](../decisions/DEC-WT035-001-SOURCE-NOMINATION-READ-MODEL.md)  
> 对应基线：指标分子、分母、方法版本、上下文和不可用状态  
> 发布状态：严格DTO草案，无HTTP路由

## 目标

把WT-034领域报告转换为严格、可复算的snake_case只读DTO，同时防止传输层把不同提名上下文合并或把自述偏好包装成真实抓取数据。

## 响应内容

- 草案契约、方法和归一化版本；
- scope、问题集快照哈希和计算时间；
- 计划、成功和失败样本基数；
- 可用性与明确不可用原因；
- 已验证样本数和解析待复核/拒绝计数；
- 按提名上下文隔离的验证方式样本数和事件数；
- 每个域名的提名率、首位提名率和提名份额；
- 提名稳定度、问题明细和空提名样本对；
- 固定的自述证据边界警告。

## 严格复核

Schema会复算和校验：

- 所有比例的`value = numerator / denominator`；
- 提名率分母等于组内已验证样本数；
- 提名份额分母等于组内事件数，所有域名份额分子之和等于事件数；
- 所有可用首位提名率使用同一分母，首位分子覆盖全部有序样本；
- 两类验证方式计数之和等于组内样本数；
- 稳定度问题数、样本对数和问题平均值可复算；
- 顶层样本数等于各组样本与解析排除样本之和；
- 同一上下文或同一组域名不能重复；
- available与not_available状态严格互斥。

## 明确不做

- 不实现查询服务、Repository或解析器；
- 不创建正式`nominated`来源事件；
- 不计算提名—引用重合；
- 不注册HTTP或OpenAPI路径；
- 不连接Provider、消费端网页或真实数据；
- 不创建迁移或修改批准基线。
