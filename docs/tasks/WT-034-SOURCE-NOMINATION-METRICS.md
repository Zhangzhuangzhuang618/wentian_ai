# WT-034 信源自述指标核心

> 状态：已完成  
> 前置决策：[`DEC-WT034-001`](../decisions/DEC-WT034-001-SOURCE-NOMINATION-METRIC-SEMANTICS.md)  
> 对应基线：`VIS-N01`提名率、首位提名率、提名份额与提名稳定度  
> 发布状态：纯领域函数和黄金样本，无解析器、Repository或HTTP路由

## 目标

用完全离线、确定性、可复算的领域函数实现AI自述信源偏好指标，并在类型和结果中明确它不是内部抓取统计或真实引用行为。

## 指标

按`nomination_context`分别计算：

- 提名率：包含域名的已验证自述样本数 / 已验证自述样本数；
- 首位提名率：域名位于位置1的样本数 / 有有效提名顺序的样本数；
- 提名份额：域名提名事件数 / 全部提名事件数；
- 提名稳定度：同一问题不同已验证样本Top-10域名集合的平均Jaccard。

报告同时返回计划、成功和失败样本基数，解析待复核/拒绝计数，两类验证方式样本数，以及固定警告`SELF_REPORTED_NOMINATION_NOT_OBSERVED_RETRIEVAL_OR_CITATION`。

## 解析与分母规则

- 成功响应样本必须全部显式表示；
- 只有`schema_validated | human_confirmed`进入分母；
- `needs_review | rejected`不得携带正式提名项；
- 每个样本最多10项；
- 同一样本重复域名在提名率中只计一次，在事件份额中按事件数计算；
- 顺序全部存在或全部为空；存在时必须为连续唯一序列；
- 无有效顺序时首位提名率不可用；
- 两个空提名集合不产生伪造的稳定度1。

## 明确不做

- 不实现真实回答解析器或提示词调用；
- 不创建`nominated`来源事件或parse review Repository；
- 不计算提名—引用重合度；
- 不合并不同提名上下文；
- 不调用Provider、消费端网页或外部URL；
- 不注册HTTP路由、创建迁移或修改批准基线。

## 测试

- 黄金样本复算四类指标；
- 重复域名只在事件份额重复计数；
- 不同提名上下文分组；
- 待复核与拒绝样本排除；
- 无验证样本明确`not_available`；
- 无顺序时首位指标不可用；
- 空—空样本对不伪装稳定；
- 样本覆盖、重复ID、非法域名、混合顺序和非连续顺序失败关闭。
