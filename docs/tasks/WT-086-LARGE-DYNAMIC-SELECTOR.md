# WT-086 大量动态数据选择器

> 状态：已完成  
> 日期：2026-08-29  
> 前置决策：[`DEC-WT084-001`](../decisions/DEC-WT084-001-CATALOG-METADATA-AND-QUESTION-GENERATION.md)

## 问题

原有动态选择器仍依赖浏览器原生 `datalist`。项目、问题集和运行增加后，会出现定位困难、长标签截断、下拉列表过长和输入时误切换记录的问题。

## 实现

- 动态选择器改为自有搜索面板，不再打开浏览器原生长下拉；
- 选中项和搜索结果分开展示主要信息与状态、时间、短编号等元数据；
- 支持多个关键词同时过滤、方向键浏览、Enter确认和Escape关闭；
- 搜索只改变候选列表，输入或失焦不会自动切换记录，必须点击结果或键盘明确确认；
- 结果面板固定高度滚动，单次最多渲染80项；超过时显示总数并提示继续搜索；
- 原生 `select` 继续作为值和 `change` 事件事实源，保持既有业务逻辑不变。

## 验收

- [x] 项目、问题集和各类运行选择器统一改造；
- [x] 长标签在选中态和结果项中分层展示；
- [x] 大于80项时列表限量且可通过多关键词定位；
- [x] 输入、失焦不会误选；
- [x] 键盘和鼠标均可明确选择；
- [x] `pnpm verify`通过。
