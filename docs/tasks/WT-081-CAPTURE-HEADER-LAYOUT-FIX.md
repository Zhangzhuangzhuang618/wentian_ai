# WT-081 采集区标题栏显示修复

> 状态：已完成  
> 关联决策：[`DEC-WT080-001`](../decisions/DEC-WT080-001-QUESTION-GROUPED-CAPTURE-VIEW.md)  
> 前置任务：[`WT-080`](./WT-080-QUESTION-GROUPED-CAPTURE-VIEW.md)

## 目标

修复运行选择器与整批接入、单次领取、一键确认按钮互相覆盖的问题，使长运行名称和不同窗口宽度下均能稳定显示。

## 实现范围

- 采集区标题和操作区改为上下分区；
- 运行选择器单独占一行并正确截断长文本；
- 三个操作按钮位于独立按钮行；
- 操作说明和自动同步状态位于独立状态行；
- 补充静态样式回归测试和全量验证。

## 明确不做

- 不修改运行、采样、自动化或复核逻辑；
- 不修改API、数据库或证据数据；
- 不调整其他页面的通用标题组件。

## 完成标准

- [x] 运行选择器不再与按钮重叠；
- [x] 长运行名称可截断且仍可正常选择；
- [x] 桌面和窄屏布局均不溢出；
- [x] `pnpm verify`通过；
- [x] 服务重建并通过健康检查。

## 验证记录

- 运行选择器、按钮组和状态说明已拆分为三个独立布局区域；
- 1180像素以下标题区改为单列，600像素以下按钮组改为单列；
- 静态资源针对性测试5项通过；
- 全量405项测试以及类型、边界、独立部署、OpenAPI和格式检查通过；
- 本机API容器已重建，数据库、对象存储、liveness和readiness均正常。
