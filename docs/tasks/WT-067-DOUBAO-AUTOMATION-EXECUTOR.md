# WT-067 豆包自动提问执行器门禁与驱动契约

> 状态：已完成（执行器边界）  
> 前置决策：[`DEC-WT067-001`](../decisions/DEC-WT067-001-DOUBAO-AUTOMATION-EXECUTOR.md)  
> 发布状态：生产授权和实机页面驱动尚未启用

## 目标

把豆包自动提问从单纯策略判断推进为可调用的执行器边界，同时保证未授权生产环境无法触发页面操作。

## 实现范围

- 自动提问驱动输入/输出契约；
- 默认关闭、地区、Surface和生产授权门禁；
- 问题、豆包页面、可见引用、完成状态和截图校验；
- 自动结果固定进入`needs_review`；
- 合成替代驱动和失败关闭测试。

## 明确不做

- 未取得授权前不操作真实豆包生产页面；
- 不自动登录、不处理验证码、不读取隐藏网络或账号凭证；
- 不把合成驱动测试记录为真实消费端样本；
- 不自动确认采集结果。

## 完成标准

- [x] 开关关闭时驱动调用次数为0；
- [x] 生产授权依据或证据缺失时驱动调用次数为0；
- [x] 官方接口授权与可见页面驱动不匹配时驱动调用次数为0；
- [x] 授权门禁满足时输出固定为`needs_review`；
- [x] 页面来源和可见证据不合法时失败关闭；
- [x] 合成执行器测试通过；
- [x] `pnpm verify`通过。

## 上线门禁

- 平台授权依据和证据编号已由项目Owner与合规责任人确认；
- 生产页面驱动已完成选择器签名、回答完成判断和失效回退烟测；
- 授权、页面签名或90天复核任一失效时自动暂停。
