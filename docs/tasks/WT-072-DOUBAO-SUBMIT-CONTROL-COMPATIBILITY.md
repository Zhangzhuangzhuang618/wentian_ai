# WT-072 豆包发送控件兼容性修复

> 状态：已完成（合成测试通过，后续实机问题转`WT-073`）  
> 前置任务：[`WT-068`](./WT-068-DOUBAO-VISIBLE-PAGE-DRIVER.md)

## 目标

修复自动提问已经把问题填入豆包输入框，但未能识别并触发当前页面发送控件的问题。

## 实现范围

- 识别按钮文字、无障碍标签、`type=submit`及测试标识中的发送语义；
- 等待前端状态更新后再选择已启用的发送控件；
- 对输入框右侧无文字图标按钮提供受限兜底；
- 排除停止、语音、附件、上传、图片、搜索和模型按钮；
- 点击后校验输入框清空、停止控件出现或新回答出现；
- 未触发发送时快速失败并给出明确提示，不再误报“问题已发送”。

## 完成标准

- [x] 带发送标识的图标按钮可以被识别；
- [x] 禁用、停止和语音按钮不会被误选；
- [x] 点击后必须检测到发送效果；
- [x] 页面签名和扩展版本同步升级；
- [x] `pnpm verify`通过。

## 完成记录

- 完成日期：2026-08-25；
- 根因：旧版驱动只识别带“发送”文字或`type=submit`的控件，无法覆盖豆包当前使用的无文字图标发送按钮；
- 修复：增加按钮标识和位置识别、等待启用、受限图标兜底、表单与回车回退，并验证输入框清空、停止控件或新回答信号；
- 版本：扩展升级至`0.0.5`，页面签名升级至`doubao-web-signature@3-submit-control`；
- 验证：全量387项测试及类型、边界、独立部署、OpenAPI和格式检查全部通过；本机API已重建且健康检查通过。
- 实机跟踪：`0.0.5`能填入问题，但豆包内部编辑器状态未同步，回车兜底产生换行且未发送；后续修复见[`WT-073`](./WT-073-DOUBAO-EDITOR-STATE-SYNC.md)。
