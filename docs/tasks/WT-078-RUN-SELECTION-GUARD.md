# WT-078 运行选择防误绑修复

> 状态：已完成  
> 决策：[`DEC-WT078-001`](../decisions/DEC-WT078-001-RUN-SELECTION-GUARD.md)  
> 前置任务：[`WT-077`](./WT-077-DEDICATED-RUN-REPORT.md)

## 目标

修复新问题集保存后仍沿用旧问题集创建运行的问题，并让采集页清楚表达当前运行与历史运行的关系。

## 实现范围

- 新问题集保存后自动选中；
- 创建运行前展示绑定摘要和计划任务数；
- 创建成功提示包含问题集、任务数和初始状态；
- 运行下拉框增加任务数、创建时间和短ID；
- 采集页增加当前运行摘要与历史运行提示；
- 静态页面回归测试、全量验证与浏览器验收。

## 明确不做

- 不删除当前误建的待开始运行；
- 不改变数据库、API、运行状态机或证据数据；
- 不增加运行删除功能。

## 完成标准

- [x] 新问题集自动选中；

- [x] 采集页当前运行信息清楚且切换正常；
