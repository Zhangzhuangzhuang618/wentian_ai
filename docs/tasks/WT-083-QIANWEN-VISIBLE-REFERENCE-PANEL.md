# WT-083 千问可见来源面板采集

> 状态：已完成  
> 关联决策：[`DEC-WT083-001`](../decisions/DEC-WT083-001-QIANWEN-VISIBLE-REFERENCE-PANEL.md)  
> 权限补充：[`DEC-WT083-002`](../decisions/DEC-WT083-002-QIANWEN-SOURCE-TAB-RESOLUTION.md)

## 目标

修复千问回答已显示正式来源、但问天预览和排名得到零信源的问题。

## 范围

- 识别千问“`N篇来源`”和“`参考来源 (N)`”；
- 展开来源面板并提取完整可见HTTP(S)目标；
- 支持公开`href`及页面可见卡片的公开URL属性，不读取隐藏网络或账号数据；
- 优先读取千问卡片公开属性中的序号、标题和URL，缺失时才临时打开来源标签读取URL后立即关闭；
- 兼容千问空白新对话编辑器暴露的占位文本；
- 升级扩展、页面签名、适配器和Surface版本；
- 保留WT-082历史运行的旧Surface版本；
- 补充单元、静态、迁移、部署与真实页面烟测。
