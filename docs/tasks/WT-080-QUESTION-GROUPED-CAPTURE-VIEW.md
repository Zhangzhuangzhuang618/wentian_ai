# WT-080 采集页按问题聚合展示

> 状态：已完成  
> 决策：[`DEC-WT080-001`](../decisions/DEC-WT080-001-QUESTION-GROUPED-CAPTURE-VIEW.md)  
> 前置任务：[`WT-079`](./WT-079-UNSTARTED-RUN-DELETION.md)

## 目标

消除“同一问题的多次采样或中断续接被显示成多个独立任务”的误解，同时保留每次采样的独立操作和审计信息。

## 实现范围

- 采集与复核列表按问题聚合；
- 问题卡片展示采样进度和状态摘要；
- 卡片内展开每次采样的操作、预览和短ID；
- 统一运行创建、运行记录、选择器及采集页的采样数量术语；
- 补充静态页面回归测试、全量验证和本地部署检查。

## 明确不做

- 不改变任务表、运行表或证据表；
- 不把多次采样物理合并为一条记录；
- 不改变整批编排、续接、统计或确认逻辑。

## 完成标准

- [x] 每个问题只显示一张主卡片；
- [x] 采样明细可展开并可执行原有操作；
- [x] 数量文案不再把采样次数误称为多个独立任务；
- [x] 自动化测试与 `pnpm verify` 通过；
- [x] 服务重建并通过健康检查。

- 全量405项测试以及类型、边界、独立部署、OpenAPI和格式检查通过；
- 独立部署仍为7个迁移，未新增数据库或API变更；
- 本机API容器已重建，数据库、对象存储、liveness和readiness均正常；
- 已部署静态资源包含问题聚合、采样明细和中断续接说明，页面未出现控制台错误。
