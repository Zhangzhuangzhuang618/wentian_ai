# WT-071 自动加载当前运行任务

> 状态：已完成  
> 前置任务：[`WT-070`](./WT-070-CLAIM-NEXT-CAPTURE-TASK.md)

## 目标

修复页面刷新后直接进入“采集与复核”时，运行下拉框已有选项但任务列表未加载、导致一键领取保持禁用的问题。

## 实现范围

- 进入“采集与复核”时读取当前下拉框选中的运行；
- 当前运行尚未加载时自动请求任务列表；
- 请求期间显示明确的加载状态并保持领取按钮禁用；
- 已加载当前运行时避免重复请求；
- 保留从“实验运行”打开任务和切换运行的既有路径。

## 完成标准

- [x] 页面刷新后直接进入第三步会自动加载当前运行；
- [x] 一键领取根据真实等待任务数自动启用；
- [x] 当前运行已加载时不重复请求；
- [x] `pnpm verify`通过。
