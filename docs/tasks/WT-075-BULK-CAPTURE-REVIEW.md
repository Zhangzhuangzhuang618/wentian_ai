# WT-075 当前运行一键确认与内容预览

> 状态：进行中  
> 决策：[`DEC-WT075-001`](../decisions/DEC-WT075-001-BULK-CAPTURE-REVIEW.md)  
> 前置任务：[`WT-074`](./WT-074-CONTINUOUS-CAPTURE-BATCH.md)

## 目标

让整批采集完成后的待复核结果可以在问天中先预览、再对当前运行一键确认，减少逐项重复操作，同时保持原有证据校验和统计边界。

## 实现范围

- 当前项目、运行和任务三重绑定的采集证据预览接口；
- 待复核和已确认任务的回答正文、可见引用与元数据预览；
- 当前运行待复核数量提示和一键确认入口；
- 不可撤销确认提示、逐项进度、部分失败提示和剩余项重试；
- 信源自述域名复核与采集确认继续分离；
- 契约、接口、页面静态检查和全量回归测试。

## 明确不做

- 不跨运行批量确认；
- 不自动确认刚上传的采集结果；
- 不提供确认撤销；
- 不在第一版直接加载或下载截图原图；
- 不自动确认信源自述提取出的域名；
- 不新增数据库表、批量事务接口或后台队列。

## 完成标准

- [x] 待复核任务可预览回答正文和可见引用；
- [x] 已确认任务仍可查看同一预览；
- [x] 一键确认仅选取当前运行的`needs_review`任务；
- [x] 操作前显示数量、统计影响和不可撤销提示；
- [x] 操作中显示逐项进度，部分失败后保留剩余任务；
- [x] 信源自述域名复核不被一键确认跳过；
- [x] 契约、接口、页面与全量验证通过；
- [x] 本机服务重建并通过健康检查；
- [ ] 用户在现有待复核运行中完成预览和一键确认实测。

## 当前验证记录

- 当前实现复用原有单任务确认接口，不新增迁移；
- 现有24项`needs_review`数据可直接用于实测，无需重新采集。
- 全量396项测试以及类型、边界、独立部署、OpenAPI和格式检查通过。
- 本机`http://127.0.0.1:3100`存活、数据库和对象存储就绪，新页面资源已生效。
