# WT-068 豆包可见页面自动提问驱动

> 状态：已完成（开发态）  
> 前置决策：[`DEC-WT068-001`](../decisions/DEC-WT068-001-DOUBAO-VISIBLE-PAGE-DRIVER.md)  
> 发布状态：生产授权待上线前补齐

## 目标

补齐从问天任务、服务端自动化预检，到豆包当前可见页面自动输入、等待回答、采集和人工确认的开发态闭环。

## 实现范围

- 自动化预检请求和响应契约；
- 一次性接入码、任务和项目设置校验；
- 默认失败关闭的部署侧授权配置；
- 浏览器扩展模式选择、自动输入、回答稳定判断和手动回退；
- 自动结果本地预览和最终人工提交；
- 合成页面驱动、服务端策略和安全权限测试；
- OpenAPI、部署说明和开发手册同步。

## 明确不做

- 未获授权前不在真实豆包页面执行自动提问；
- 不自动登录、不处理验证码、不读取隐藏网络或账号凭证；
- 不做后台无人值守批量调度；
- 不自动确认采集证据。

## 完成标准

- [x] 服务端预检在任一门禁缺失时失败关闭；
- [x] 扩展只有取得服务端`ready`结果后才输入问题；
- [x] 合成页面测试覆盖输入、完成判断、可见回答选择和超时回退；
- [x] 自动采集必须经过本地预览和最终确认；
- [x] 扩展权限未扩大；
- [x] 文档、自审和`pnpm verify`通过。
