# WT-064 项目删除与跨存储清理

> 状态：已完成  
> 前置任务：[`WT-063`](./WT-063-CONSUMER-EVIDENCE-RETENTION.md)  
> 前置决策：[`DEC-WT064-001`](../decisions/DEC-WT064-001-SCOPE-DELETION.md)

## 目标

为问天独立版提供由项目 Owner 显式发起、可审计且可重试的项目删除闭环。

## 实现范围

- `0006`项目删除状态和项目外删除作业；
- Owner、项目标识、密码、版本和CSRF五重确认；
- 删除期间停止写入并撤销短期采集凭据；
- PostgreSQL级联删除与S3项目路径清理；
- 删除失败重试、最小审计和独立版Web入口；
- 接口、仓储、对象存储和跨项目隔离测试。

## 完成标准

- [x] 非Owner、错项目、错密码、旧版本和跨项目请求失败关闭；
- [x] 接受删除后项目立即不可继续创建运行或上传；
- [x] 数据库与对象存储均无该项目业务残留；
- [x] 对象存储失败时保留可重试删除作业，不返回成功；
- [x] 重试幂等且不影响其他项目；
- [x] GEO解绑与项目删除语义保持分离；
- [x] `pnpm verify`和真实PostgreSQL 16/S3演练通过。
