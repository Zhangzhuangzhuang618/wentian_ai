# WT-004 方法与外部能力门禁

> 状态：等待产品确认  
> 原任务号：WT-003；因消费端观察优先顺延  
> 对应基线：`CHG-VIS-002`、`VIS-P01`  
> 性质：产品与合规门禁，不是Provider开发任务

## 目标

在实现联网信源契约、数据库迁移和Provider Adapter前，冻结首发外部能力、方法版本、预算和保留规则，防止用假能力或未批准字段继续开发。

## 待确认项

1. 首发Provider和真实model ID；批准基线的首选候选为OpenAI Responses Web Search，但候选不等于已批准；
2. 是否采用方法版本 `ai-source-observatory@1`；
3. 是否采用每题默认3样本、允许1至5样本，以及单次运行和月度预算上限；
4. 原始回答、Provider白名单元数据和来源事件的允许保存字段与保留期；
5. Provider当前条款、账号能力、允许地区、责任人和复核日期。

## 门禁规则

- 未确认首发Provider和model ID时，不实现真实Adapter；
- 未完成条款与字段审批时，Provider状态只能是 `draft` 或 `disabled`；
- 未确认预算时，不创建可绕过预算的运行入口；
- 不使用浏览器自动化冒充Provider API；
- 不在仓库、文档、测试数据或数据库保存Provider密钥。

## 完成标准

- [ ] 五项待确认内容形成书面决策；
- [ ] 决策与批准基线无冲突；
- [ ] 明确允许保存的Provider字段和保留期；
- [ ] 明确预算上限和超限行为；
- [ ] 为后续联网信源契约任务签发正式任务号。

## 后续依赖

WT-004完成后进入联网信源契约任务，对应 `VIS-P02`。数据库迁移 `VIS-P03` 必须同时依赖已完成的WT-002和信源契约，不得提前创建。
