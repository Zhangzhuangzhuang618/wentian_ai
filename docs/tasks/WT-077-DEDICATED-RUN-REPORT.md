# WT-077 独立运行结果详情页

> 状态：已完成  
> 决策：[`DEC-WT077-001`](../decisions/DEC-WT077-001-DEDICATED-RUN-REPORT.md)  
> 前置任务：[`WT-075`](./WT-075-BULK-CAPTURE-REVIEW.md)、[`WT-076`](./WT-076-DOUBAO-REFERENCE-PANEL-CAPTURE.md)

## 目标

把工作台中的长排名列表拆为独立浏览器标签页报告，让用户先查看运行汇总和图表，再下钻单问题精确数据。

## 实现范围

- 已完成自然回答运行的“查看结果”入口；
- 排名区“打开引用详情”和“打开对照详情”入口；
- 同源、可刷新、可重新登录后恢复的报告URL；
- 自然回答任务汇总、正式条目、独立域名和问题覆盖；
- 全运行Top域名图、单问题信源密度图；
- 单问题汇总表和可展开域名排名；
- 信源对照任务汇总、平均Top 10重合、双侧域名图和单问题双侧排名；
- 纯函数展示模型、静态资源路由和自动测试；
- 产品决策、任务记录和深度自审。

## 明确不做

- 不新增数据库表、迁移、服务端缓存或后台报表任务；
- 不改变正式信源、排名、提名或重合指标口径；
- 不引入第三方图表库；
- 不增加PDF、图片、CSV导出；
- 不在本轮新增跨运行趋势或时间序列图。
