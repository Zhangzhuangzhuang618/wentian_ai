# WT-079 深度自审

> 日期：2026-08-26  
> 结论：范围、权限、并发、证据边界、界面状态和部署验证通过

## 自审范围

- 未开始运行删除的产品边界；
- 实例Owner、项目Owner、scope隔离、同源和CSRF门禁；
- PostgreSQL事务、并发领取、配对运行和外键行为；
- 采集包、确认记录、截图对象、正式信源与排名的保护；
- 删除后的前端运行列表、运行选择器和当前任务状态；
- 契约、测试、部署和既有数据影响。

## 发现与处理

| 编号      | 风险                                             | 处理                                                            | 结果   |
| --------- | ------------------------------------------------ | --------------------------------------------------------------- | ------ |
| SR-079-01 | 把删除入口开放给已开始或已完成运行会破坏证据事实 | 只允许`queued`且全部任务为`waiting_user`                        | 已处理 |
| SR-079-02 | 异常数据可能保持等待状态但已有证据               | 额外检查采集包和确认记录，任一存在即拒绝                        | 已处理 |
| SR-079-03 | 删除与任务领取并发导致刚领取的任务被清理         | 事务内锁定项目、运行和全部任务；领取更新在删除提交后失败关闭    | 已处理 |
| SR-079-04 | 配对运行通过外键引用目标运行                     | 删除前检查`paired_run_id`引用；外键并发冲突转为不可删除         | 已处理 |
| SR-079-05 | 只校验实例角色会越过项目权限                     | 同时校验实例Owner、项目Owner和允许scope                         | 已处理 |
| SR-079-06 | 无CSRF请求可以利用登录Cookie删除                 | 删除路由复用同源与CSRF写入门禁                                  | 已处理 |
| SR-079-07 | 删除当前选中运行后页面继续请求失效ID             | 清空当前运行、任务和接入卡，再刷新目录和选择器                  | 已处理 |
| SR-079-08 | 删除运行误删问题集或其他运行                     | 只按`scope_id + run_id`删除运行；问题集外键为RESTRICT且不被删除 | 已处理 |
| SR-079-09 | 已有截图对象因级联产生孤儿                       | 有采集包即拒绝删除，因此本功能不触碰对象存储                    | 已处理 |
| SR-079-10 | 把早期不可执行OpenAPI草案伪装为本地管理API文档   | 仅同步独立版Zod响应契约和任务文档，保留草案原边界               | 已处理 |
