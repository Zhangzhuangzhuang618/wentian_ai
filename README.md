# “问天”AI信源探测系统

“问天”是可完全独立部署的AI信源探测系统。第一版独立运行不依赖Redis、GEO Content OS或第三方模型API；需要集成时，GEO只通过独立连接器接入。

## 当前可用能力

- 本地Owner登录、会话、项目和项目级权限；
- PostgreSQL 16、S3兼容对象存储、从`0001`连续编号的迁移；
- Docker Compose独立部署和一次性Owner初始化；
- 问题集、自然回答实验和“AI自述信源推荐”实验；
- 豆包网页版可见页面采集：支持单题自动提问、整批连续采集和用户手动选择回答；单题与手动模式保留本地预览，所有模式提交后均需在问天最终复核；
- 同一问题多次回答的信源条目累计排名；
- 自然回答引用与AI自述推荐的并排对照、Top-K重合；
- 以实际开始时间为准、最大间隔24小时的配对实验可比性门禁；
- 自动化开关默认关闭；浏览器可见页面驱动已完成开发态实现，生产部署默认授权依据为`none`，未接入书面授权证据前不会操作真实页面；
- 保留期清理：待复核包24小时、确认截图30天、回答/可见引用180天；正式域名和规范链接事实保留至项目删除。
- 项目删除：撤销GEO访问和短期会话，清除PostgreSQL项目数据与S3项目对象；
- 可选GEO薄连接器：项目绑定、一次性登录、问题集同步、解绑和访问撤销；问天独立运行不依赖该连接器。

该系统测量的是消费端页面可见回答、可见引用以及AI自述的信源推荐。它不能据此推断模型内部真实抓取频率、训练数据权重或未公开检索日志。

## 快速开始

1. 将`.env.example`复制为`.env`并填写四项秘密；
2. 运行`docker compose up -d --build`；
3. 按[独立版部署手册](./docs/STANDALONE-V1-RUNBOOK.md)完成唯一Owner初始化；
4. 打开`http://127.0.0.1:3000/`登录；
5. 按[豆包采集器说明](./apps/browser-extension/README.md)加载本地扩展。

完整校验：

```bash
pnpm verify
```

开发态API：

```bash
pnpm dev:api
```

- `GET /health/live`：进程存活检查；
- `GET /health/ready`：PostgreSQL和对象存储真实就绪检查。

## 当前边界

- Git仓库尚未初始化，等待项目所有者创建；
- 第一版没有Redis或独立Worker；GEO连接器为可选集成，不是独立运行依赖；
- 没有生产Provider调用；
- 豆包自动登录、凭证读取、Cookie读取、验证码绕过和隐藏接口采集均未实现；
- 生产自动提问保持外部授权门禁阻断，手动采集可用；
- 浏览器页面选择器仍须在授权接入后完成真实页面烟测；合成测试不能替代该上线门禁。
