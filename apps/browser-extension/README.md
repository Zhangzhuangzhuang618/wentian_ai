# 问天浏览器辅助采集器

这是问天消费端可见页面采集器。当前版本`0.0.23`支持豆包、千问和 DeepSeek Web 的“连续采集整批”“自动采集单题”和“手动选择当前回答”。所有模式都必须由用户在当前 AI 页面主动启动，扩展不读取账号凭证。

## 当前流程

1. 用户在问天选择一个运行。单题模式领取任务并复制10分钟有效的一次性接入码；整批模式点击“整批接入”并复制两小时有效的整批接入码；
2. 用户自行登录豆包、千问或 DeepSeek，打开当前聊天页并点击扩展图标；
3. 选择“自动采集单题”时，扩展先把一次性接入码交给本机问天预检。问天校验项目开关、令牌、任务、地区和部署侧授权后，只返回当前任务问题；任一门禁不满足时页面不会被操作；
4. 预检通过后，扩展在当前可见页面填入问题、发送、等待“停止生成”控件消失且回答文本连续稳定5秒；最长等待3分钟，失败后可改用手动选择；
5. 回答稳定后，扩展识别当前回答附近的“参考 N 篇资料”“N篇来源”或“参考来源 (N)”入口，展开面板并读取完整的可见HTTP(S)链接；千问优先读取当前可见来源卡片公开属性中的序号、标题和URL，缺失时才逐项打开临时来源标签、读取地址、立即关闭并返回千问；如果页面声明有N篇资料却未读全，本题停止且不提交；
6. 选择“手动选择当前回答”时，用户自行提问并单击选择回答区域；同样会读取当前回答的可见参考资料面板；
7. 选择“连续采集整批”时，只粘贴一次整批码。扩展会逐题领取短期一次性凭证，并循环执行新建对话、预检、发送、等待、采集、提交和领取下一题；失败即暂停，可重试或停止；
8. 单题和手动模式会在本地展示回答正文、回答区域内及参考资料面板中实际可见的HTTP(S)链接、文本信源提示和区域截图，并由用户逐题确认；文本信源提示固定标记为“非引用”；
9. 整批模式不逐题展示扩展预览，而是把用户的一次批次启动视为本地导出确认。每项提交后仍只进入问天`needs_review`；用户可回到问天预览结果，并对当前运行逐项确认或一键确认，未经确认不会计入排名；
10. 连接失败时整批流程暂停；单题或手动流程可导出本地JSON。

## 权限

- `activeTab`：只在用户点击扩展图标后临时访问当前标签页；
- `scripting`：在该次用户触发后注入选择和预览界面。
- `tabs`：仅作为千问可见来源卡片没有公开URL时的回退，识别由当前千问页打开的临时来源标签、读取URL、关闭标签并返回原页；代码不枚举既有标签页。
- `http://127.0.0.1/*`、`http://localhost/*`：把用户确认的数据提交到本机问天；代码会再次校验接入码中的地址，不能改发到外部服务器。

该组合符合Chrome官方的 [`activeTab`](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[`chrome.scripting`](https://developer.chrome.com/docs/extensions/reference/api/scripting) 和 [`chrome.tabs`](https://developer.chrome.com/docs/extensions/reference/api/tabs) 规则；当前视口截图由 `captureVisibleTab` 完成。千问临时来源标签必须同时满足“由当前千问标签打开”和“同一窗口”两个条件。

扩展不申请Cookie、存储、下载或网络监听权限，也不读取浏览历史、来源页正文或页面私有状态。除千问可见来源卡片产生的临时标签外，扩展不控制其他标签页。单题与整批接入码只保留在当前内容脚本内存中，关闭或重新加载后不会恢复。

## 本地加载

在正式安装演练获得批准后，打开Chrome扩展管理页、启用开发者模式，并选择“加载已解压的扩展程序”，目录指向本目录。

`0.0.10`读取豆包“参考 N 篇资料”面板；`0.0.11`新增千问Surface；`0.0.12`读取千问“来源”面板中的完整可见链接；`0.0.13`兼容千问空白编辑器占位文本；`0.0.14`增加千问临时来源标签回退；`0.0.19`优先读取千问可见来源卡片公开属性中的`refer_num`、标题和URL，并保留临时标签回退；`0.0.20`修复千问侧边栏展开后“新建对话”入口无法识别的问题；`0.0.21`在读取千问来源卡片后将回答区域恢复到可见视口；`0.0.22`新增 DeepSeek Web 独立 Surface、聊天路径、输入占位和新对话识别；`0.0.23`按真实页面入口补充“开启新对话”识别并升级 DeepSeek 页面签名。DeepSeek 首版只采集回答区域内真实可见的HTTP(S)链接，不声明已经解析其独立来源面板。升级后需在扩展管理页点击扩展卡片右下角的圆形箭头重新加载，随后刷新目标页面，避免旧内容脚本界面残留。部署默认配置为`production + none`，因此未接入对应平台书面授权证据前，生产自动提问会在服务端失败关闭，手动采集仍可使用。

## 自动化上线门禁

- 项目自动化开关已由Owner打开；
- 部署侧`WENTIAN_DOUBAO_AUTOMATION_AUTHORIZATION_BASIS`为`written_permission`；
- 对千问或 DeepSeek 运行，必须改用各自平台的同名独立部署变量；
- 部署侧存在经Owner和合规责任人确认的非空证据编号；
- 授权复核时间合法且距当前不超过90天；
- 页面签名、输入、完成判断、失效回退完成真实页面烟测；
- 任一条件失效时恢复为手动采集。

## 选择提示

扩展优先选择包含更多“参考来源/信息来源/参考 N 篇资料”信号的回答外层区域，降低误选为单个段落的概率。预览中仍必须核对正文范围和可见链接数量；范围不完整时使用“重新选择”，不能直接确认。页面正文里只有名称、没有真实链接的来源仍是“非引用”，不会进入正式信源排名。
